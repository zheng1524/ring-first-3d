# 方法与隔离边界

本轮沿用已修复的 PyTorch3D/坐标/可见性代码。A0 复现脚本 `train012_exact.py` 直接复制 012 原训练循环；原九例初值逐位等于 011 FINAL。新增 G10/G11 使用同一已运行的真实视频 → INITMask → Ring 解算 → SIFT 轨迹/两固定相机初值 → HERO 原生轴向深度流程；旧 Gate 标签只记录，不据此拒绝。

新病例没有历史 011，必须明确区分配方等效新初始化。它们先采用 009 的通用九参数/有界星凸与 C 选择，统一修复宽接触时 WEAK 不否决冠面，再运行 011 的固定 300 候选安全更新。未按 Ip 标签改变模型或优化器。G10/G11 的基底接触实际不为 BROAD，故未强制截断。

A1 是前景漏覆盖与已知背景误覆盖的分别归一化 MSE，原全图损失不取消。A2 固定真实 Mask 轮廓距离场；共享 Mesh 的前后面邻接边/开放边产生真实三维轮廓样本，投影后对距离场双线性查询；逆向由真实轮廓到当前投影边采样最近邻。离散可见性/最近邻每次重算，不传播其离散选择梯度。对边三维位置及投影传播梯度，不将固定像素的重心坐标误当移动轮廓。CAD/自遮挡以及既有 Ring 负证据保护参与筛选，不能用全 Ring 永久排除代替。

A3 的权重随候选编号升高，但每次原状态与候选都重算相同权重的目标。不同臂的原始总损失不直接互相比，统一 FIT 固定分母指标用于预注册选择。

O1 仅改变学习率恢复/信赖域调节；O2 将前40候选的方向投影到共享平移+三轴尺度的六参数子空间，随后释放原自由顶点；O3 在全局方向失败后尝试四个固定两跳局部梯度补丁；O4 仅放宽累计位移上限，单轮位移、CAD、基底、面片和自交检查保持不变。没有任何病例专属的权重、算法、柄部分割。

几何检查保留真实三角形 CAD 接触与离散签名采样、反向 Ring 点，以及非邻接自交检测。采样非穿透不等于数学上连续的全表面非穿透证明；独立 Blender 检查仍须报告穿环三角形对。原先已有碰撞不伪称安全。

最佳刚性评价与学习严格隔离。仅全体预测和 Ring 尺度冻结后读取 Blender；纯主体不含 Ring/背景，推断底盖不参与配准和主要表面距离。96个固定正旋转初值经粗 ICP，再对前8个采用真正双向最近曲面对应的等质量刚性 Kabsch 更新和 SE(3) 回溯。固定尺度1，无镜像。所有指标使用每模型同一个最优T；次优独立姿态、候选残差保留。此处“最佳”为固定搜索内的最佳，并非全局最优认证。011/012/013统一重算。

## 优化前数值诊断

修复过一次诊断脚本的星号导入覆盖：`gradient_preflight.py`被`strategy`再次导出的旧`Objective`覆盖，导致最初A1/A2/A3未执行。原无效诊断单独保存`GRADIENT_PREFLIGHT_REJECTED_IMPORT_PROBE.json`，不作为通过证据；正式训练脚本一直使用显式策略函数导入，没有该覆盖。

新增距离项使用FP64连续查询；真实G03/G01/G02的9个相机固定可见性、轮廓边及最近邻分支后，自动微分与有限差分相对误差<2e-10。完整目标仍分段且会跳变：G01原有射线命中分支在±0.0001mm参数范数探针附近发生ref03 228→227命中、306→302有效点对变化；G03新轮廓可见样本也可能在射线边缘发生离散切换。因此`GRADIENT_PREFLIGHT.json`的passed仅表示有限非零梯度，绝不表示完整离散目标处处通过有限差分。所有原始+/-探针项均保留，最终接受仍使用真正重算的完整目标和几何检查。

## G03位移范围与停滞的区分

追加只读诊断，不新增优化方法或调权：将初始真实三角面投影到每条固定漏覆盖射线的正交平面，计算原点到投影三角形并集的最短距离。这是固定三角形/逐顶点移动条件下必须达到的最大顶点位移下界；不是GT深度，也不是充分可行条件。计算通过独立平行三角形和投影内部控制验证。

G03三个FIT视角各固定256条远漏覆盖射线，最大连续曲面→射线距离约7.192/6.014/5.675mm，82/42/31条的下界超过原4.778mm总位移上限。因此原上限可能限制最终最远轮廓恢复；但012实际只移动0.000341mm，未触碰该上限，故不能用上限解释当前早期停滞。O4只放宽范围，保持原优化器，用于隔离这一因素；若优化器仍未接近上限，不能将O4未改善解释为未来范围永远无关。

投影缺口主要由8–11个初始最近顶点支撑，可能带来局部拉伸/采样压力；不能据此证明固定拓扑无法表示柄。未进行额外细分或隐式表达搜索，本轮限制不扩展。

新增病例的`initialization_011/metrics/PREFLIGHT.json`明确是输入发布标志，不是历史011完整病例资格门禁的重跑；原011的病例硬路径不适用于新增编号。新初始化称为“011优化配方等效”，不称完整011审计复现。每次初始化候选仍执行原几何guard，最终另做统一原坐标与Blender几何检查；初始化存在的碰撞/失败不被该发布标志认证为物理正确。

`UPDATE_HOLDOUT`仅表示本轮Mesh更新不使用该图像；已有相机恢复、输入选择与上游相关性不是严格全链路独立GT认证。该角色不会用于本轮损失/优化方案选择。跨视角HERO一致性不进入损失、权重、观测筛选或终止条件。
