# 方法与隔离边界

本轮沿用已修复的 PyTorch3D/坐标/可见性代码。A0 复现脚本 `train012_exact.py` 直接复制 012 原训练循环；原九例初值逐位等于 011 FINAL。新增 G10/G11 使用同一已运行的真实视频 → INITMask → Ring 解算 → SIFT 轨迹/两固定相机初值 → HERO 原生轴向深度流程；旧 Gate 标签只记录，不据此拒绝。

新病例没有历史 011，必须明确区分配方等效新初始化。它们先采用 009 的通用九参数/有界星凸与 C 选择，统一修复宽接触时 WEAK 不否决冠面，再运行 011 的固定 300 候选安全更新。未按 Ip 标签改变模型或优化器。G10/G11 的基底接触实际不为 BROAD，故未强制截断。

A1 是前景漏覆盖与已知背景误覆盖的分别归一化 MSE，原全图损失不取消。A2 固定真实 Mask 轮廓距离场；共享 Mesh 的前后面邻接边/开放边产生真实三维轮廓样本，投影后对距离场双线性查询；逆向由真实轮廓到当前投影边采样最近邻。离散可见性/最近邻每次重算，不传播其离散选择梯度。对边三维位置及投影传播梯度，不将固定像素的重心坐标误当移动轮廓。CAD/自遮挡以及既有 Ring 负证据保护参与筛选，不能用全 Ring 永久排除代替。

A3 的权重随候选编号升高，但每次原状态与候选都重算相同权重的目标。不同臂的原始总损失不直接互相比，统一 FIT 固定分母指标用于预注册选择。

O1 仅改变学习率恢复/信赖域调节；O2 将前40候选的方向投影到共享平移+三轴尺度的六参数子空间，随后释放原自由顶点；O3 在全局方向失败后尝试四个固定两跳局部梯度补丁；O4 仅放宽累计位移上限，单轮位移、CAD、基底、面片和自交检查保持不变。没有任何病例专属的权重、算法、柄部分割。

几何检查保留真实三角形 CAD 接触与离散签名采样、反向 Ring 点，以及非邻接自交检测。采样非穿透不等于数学上连续的全表面非穿透证明；独立 Blender 检查仍须报告穿环三角形对。原先已有碰撞不伪称安全。

最佳刚性评价与学习严格隔离。仅全体预测和 Ring 尺度冻结后读取 Blender；纯主体不含 Ring/背景，推断底盖不参与配准和主要表面距离。96个固定正旋转初值经粗 ICP，再对前8个采用真正双向最近曲面对应的等质量刚性 Kabsch 更新和 SE(3) 回溯。固定尺度1，无镜像。所有指标使用每模型同一个最优T；次优独立姿态、候选残差保留。此处“最佳”为固定搜索内的最佳，并非全局最优认证。011/012/013统一重算。
