## 2. Gate A：IIa6.5_R10 单场景，**本轮立即完成**

### A1. 冻结观测和相机契约

优先使用 RA 指定 IIa6.5_R10 的**原生 Blender CAD**及既有相机与 Ring；保留 `obs00, obs01, obs03, obs04, obs05` 五视角，固定训练 `obs01/03/05`、留出 `obs00/04`。多视角使用**一个共享三维主体**。

- Blender 原生主体资产导出到毫米（主体顶点 ×1000；Ring 已为毫米）；冻结 70° FOV、K、c2w、Ring CAD、RGB/Mask、有效 ROI、UNKNOWN 和遮挡定义。沿用既有 Blender↔CV 轴系 `diag(1,-1,-1,1)`，查明 Open3D 的像素中心与 Blender 边缘坐标之间的 `c_x,c_y −0.5` 约定。
- 先做既有 Blender / Open3D 渲染等价核验：原生 Ring 与主体预测 Mask **IoU≥0.99**，轮廓 p95 **≤1 原始像素**，三维点投影偏差 **<0.001 px**；不通过时暂停相应 N0 实验，修正接口而非放宽门槛。
- GT 原生 Mesh 仅能用于**生成冻结的二维目标**及**所有预测冻结后的独立三维评价**。优化器不得读到 GT mesh、GT 深度、真实 SDF 参数、GT 顶点或任何 `audit_only` 文件；保留/加强已有 `E4_OPTIMIZER_ONLY` 防火墙。不存在原生 CAD 的“正确四维 Wendland 真值 `q_GT`”，不得凭空定义。
- P0 应是真实可追溯的保守椭球/低维 SDF 初始化；若旧 `BASE_FIELD` 与此不一致，明确新建 N0 输入而非挪用旧对照文件。初始化如与 Ring 穿插，先记录碰撞事实与来源；禁止静默平移修好。
- 固定输入清单、固定有效观测像素分母、每视角采样/残差权重与随机种子。若多视角资格不足，说明证据并中止 N0 的相应结论，不随意替换相机/画面。

### A2. **先做只读可观测性与目标函数审计**（优化前）

对当前真正参与优化的参数 `q` 和全部训练观测，计算数值雅可比：

\[
J_{ij}\approx\frac{r_i(q+\varepsilon_j e_j)-r_i(q-\varepsilon_j e_j)}{2\varepsilon_j}.
\]

执行细节：

1. 以**同一组固定索引**定义双向/连续轮廓或有符号距离场残差，统一 px 标度及权重；可采用固定图像采样点上的亚像素 SDF/连续投影边界距离。`cv2.findContours` 每次生成的可变整数像素边界及最近邻关联，不能原样直接构成相互可比较的雅可比行。
2. Ring CAD 遮挡、UNKNOWN、ROI、前景/背景判定，对 `q±ε` 完全一致；不要让变化的有效像素数引入虚假梯度。记录每视角有效像素和可见几何支持。
3. 以可解释的物理单位（平移 mm、旋转 rad、核幅度对应的公制表面位移）进行参数列归一化，对残差按噪声/视角和量纲合理白化。报告每视角子雅可比、全体 SVD、奇异值及近零方向，检验 `ε` 与 `ε/2` 结果稳定性；对不可微/拓扑跳变点要标记失效。
4. 取最弱奇异右向量及代表性可观测方向，分别作**正、负**真实曲面幅度约 **0.2–0.5 mm** 的受控扰动。计算并展示每视角二维轮廓/IoU/亚像素 p95 变化、三维最大/中位位移、Ring 接触/相交和拓扑变化。若某方向无法形成有效网格，记录原因。
5. 额外验证**轮廓损失的目标正确性**：在旧同核控制中可以对比已知同核真值参数的 loss 与错误解 loss，检查旧 `0.21–0.37 px` 偏差及扩张/收缩不对称是否可复现；但 N0 原生 CAD 没有 q_GT，只能用独立 GT 三维评价与已知受控形变判断。不要仅凭“目标轮廓不同”推断损失具有有效下降方向。

判定应明确区分：**局部雅可比弱奇异值只能证明局部弱可观测性，不能单独证明全球形状不唯一**；必要时展示两份不同三维形态产生相似二维解释的实例。

## 4. 统一指标与科研报告判定

每臂固定**三个训练/两个留出视角**，至少报告：

- **二维**：每视角 IoU、对称亚像素轮廓距离 mean/p95、Mask 外预测面积比例、FP/FN 像素数及固定分母；Ring 遮挡/UNKNOWN 数量单列。
- **三维（后验 GT 审计）**：可见与未知区域分开的 Chamfer / p95（mm）、最大/中位公制位移、中心偏差、主轴/长宽高、体积及表面积的相对误差，新增/删除体积的单独恢复率，几何碰撞、自交/拓扑状态。**不要仅给 Chamfer 代替差异体积。**
- **可观测性**：白化后的 Jacobian 奇异值/条件数、各方向的 mm→px 灵敏度、视角贡献与冲突、改变 `ε` 的数值稳定性；必要时输出弱模态的二维相似而三维不同的证据。
- **优化**：每步四参数及实际 Mesh 变化、逐视角损失、接受/拒绝更新及原因；固定评估数据与分母，不删失败行、不降低覆盖率以换好指标。

涉及 SDF 场的比较采用旧 `METRIC_CONTRACT_NOTE.md` 的**固定空间采样点/相同评估算子**：欧拉意义的 GT/预测场差异不可偷换成顶点材料位移；可另行报告法线射线位移并保留 missing-ray。对于开放表面和不可见区域，不推断无依据的闭合体积；写明哪个指标有定义。

最后回答七个问题：

1. 相似 Mask 下能出现多大的真实三维差异（mm、体积）？
2. 哪些形变参数由当前三个视角独立支持，哪些仍处于近零空间？
3. 旧轮廓目标的偏差是否真实存在，并足以改变优化方向？
4. Gate A 的失败更符合观测、损失、搜索、表达哪一类，证据强度如何？
5. 改用更准确的亚像素损失，是否在**固定 Powell**条件下改善训练与留出视角以及后验三维？
6. 下一步应先增加视角、改连续边界目标、换低维求解器，还是增加模型表达能力？这些措施的优先顺序是什么？
7. N0 验收后哪些 B/C/D 执行条件已满足，哪些不能推进？

Gate A 结束提交上述成果后，明确写：**“Gate A 已完成；Gate B/C/D 未运行，待人工确认。”** 若 Gate A 科学上失败，也应提交可观测性、数值接口或表示失效的证据，不以训练效果漂亮作为完成条件。
