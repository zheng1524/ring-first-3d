# 覆盖率、轮廓误差及图中MAE的含义

这些是把A的既有HERO几何投影到真实B图像后，检查二维解释程度的指标；没有独立真实相机/三维形状GT，所以不等于绝对相机精度或三维重建准确率。

**息肉覆盖率：B中实际标出的息肉区域，有多少像素被A投过来的息肉几何覆盖。越高表示能解释的目标区域越多。**

设M为B原始Polyp Mask像素集，V为经过正深度、深度排序和CAD遮挡后仍有效的预测Polyp投影，则：

`coverage = |V ∩ M| / |M|`。

例如，B有1000个息肉像素，预测覆盖其中700个，覆盖率就是70%；剩余300个没有被当前A来源解释。分母始终是B完整Polyp Mask，不会只用模型命中的像素来当分母。A没有看见的新侧面、源深度缺失、遮挡、点云采样空隙、深度或相机偏差都可能让覆盖下降，不能只凭覆盖下降就判定相机错误。大角度时A、B可见面差异增加，覆盖下降可能有合理来源。

覆盖率本身没有惩罚Mask外多投的区域，因此还要看越界比例和轮廓。`outside_fraction = |V \ M| / |V|`；Mask外多投得多，意味着几何/投影与分割有不一致，但分割边界及遮挡也有不确定性。

**当前五面板里两种覆盖率使用不同的预测表示，应分别读：**

- “旧Polyp-only原三角面覆盖”：V来自A原始三角面的首次射线交点，CAD容差.05mm。旧/新帧对的轮廓误差也采用这个口径。
- “新点云场景P覆盖”：V来自真实离散XYZ的最近像素中心及深度排序，CAD容差.002mm，点与点之间不填充。绘图点大小不会扩大计数范围。因此即使显示看起来较连续，这个覆盖也可能比三角面低。
- BG覆盖：仅针对旧协议中固定的B背景评价ROI及背景Mask，不是全图背景覆盖，也不是Polyp覆盖。

本次G01 r14→r00，原三角面RF覆盖为69.84%，轮廓MAE为8.72px；同一五面板中点中心P覆盖更低，这是离散表示和遮挡规则的差别，不能把两者混成同一指标。

**轮廓误差：预测投影的边缘，与B真实Polyp Mask边缘平均相差多少像素。越小表示二维边缘越贴合。**

代码先取两张二值区域的全部轮廓。对每个预测边缘像素，找最近的B Mask边缘；再反过来，对每个B边缘像素找最近的预测边缘。把两组距离拼接后求平均，得到表中的轮廓MAE；p95是其中95%的距离不超过的值。

`boundary_MAE = (sum_{p in ∂V} min_{q in ∂M} ||p-q|| + sum_{q in ∂M} min_{p in ∂V} ||q-p||) / (|∂V| + |∂M|)`。

例如2px表示这两组最近边缘距离平均为2个**原始640×360评价图**的像素，不是保存大PNG上的2像素，也不是2mm。当前实现保留孔洞、CAD切出的边界及碎片边界，不只计算最外轮廓；这是既有定义，本轮没有偷偷改成只选主体边缘。空轮廓不可评价，不能记为0。

**图底的“MAE xx/255”是RGB颜色误差，不是轮廓误差。**

它是在规定有效区域内，对预测RGB与B原图每个通道的绝对差求平均。范围0–255，越小表示图像颜色越接近。正式RF/SIFT配对主比较使用双方都有效的共同Polyp区域；追加完整场景对照另有P/BG共同支持的显示诊断。应结合各自分母与覆盖阅读；只有很小共同区时，RGB误差再低也不代表解释了整颗息肉。光照、高光也会改变这个数。

二维覆盖和边缘都好，仍可能存在错误深度、重复层或未观测表面的错误推断。图中的R差异、t方向夹角则是SIFT相对RF的差异，当前没有相机GT，不能叫绝对位姿误差。

定义对应代码：`code/experiment_a.py:metrics`，点中心显示对应原AB-FULL-SCENE-002的`point_projection`与`scene_metrics`；本轮仅解释、复用，没有调整评价标准。
