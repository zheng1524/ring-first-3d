# CONTOUR_MODEL_DESIGN

## 目标

把 Ring 的二维观测从「Mask 散乱边界点」升级为「连续、可解释、内外分离的曲线」，
并允许曲线偏离理想椭圆（上一轮 A1 直接以 DXY 椭圆为目标失败的原因）。

## 表示

```
Γ(s) = Γ0(s) + δ(s) · n(s)
```
- `Γ0`：DXY 内外椭圆的等弧长重采样（n=180）。
- `n`：外向法向（按环心定向）。
- `δ(s)`：4 阶 Fourier 级数（8 个系数），保证闭合、平滑、非椭圆。

## 能量（B2）

```
E = E_edge + λ_s E_smooth + λ_d E_dev + λ_w E_width
```
- `E_edge`：沿法向的 RGB 梯度奖励，`1 - min(|∇I|/80, 1)`。
- `E_smooth`：δ 的二阶差分。
- `E_dev`：δ 的 L2（不远离 DXY 先验）。
- `E_width`：内外宽度关系（保留物理环宽）。

**可见弧支持域**：以 DXY 曲线采样点到真实 Ring 像素的最近距离 ≤3 px 判定可见；
不可见弧段的 δ 强制置零（只作先验，不强监督）。

## 本轮实测

| 轮廓 | 平均 \|δ\| (px) | B2 到真实 Mask 边界 | DXY 到真实 Mask 边界 |
|---|---:|---:|---:|
| inner | **0.000** | 0.614 px | 0.615 px |
| outer | 0.382 | 0.857 px | 0.632 px |

**B2 只在 4/10 条轮廓上更接近 Mask 边界，且内轮廓完全没有移动。** 见 `FINAL_REPORT.md` 的失败归因。
