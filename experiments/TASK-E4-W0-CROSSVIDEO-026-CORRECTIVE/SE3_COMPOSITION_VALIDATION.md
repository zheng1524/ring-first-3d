# SE3_COMPOSITION_VALIDATION

## 约定

`H = H_{005←004}`，`X₀₀₅ = H X₀₀₄`；c2w；Ring CAD 与两段世界原点重合。
`RingRenderer.losses(H_in, cid)` 内部：`C = canonical(H_in @ d['T'])`（`d['T']` = W0 c2w）。
因此 `H_in` 必须是**增量**：`H_in = T_pert @ T₀⁻¹`。

| 情形 | 传入增量 |
|---|---|
| 004 相机进入 005 帧 | `H` |
| 005 相机进入 004 帧 | `H⁻¹` |
| 世界系扰动 `dH_world` | `dH_world` |
| 相机局部扰动 `dH_local` | `T₀ dH_local T₀⁻¹` |

## 测试（`runs/G03/SE3_COMPOSITION_TESTS.csv`）

| 测试 | 最大矩阵差 | 端到端损失等价 |
|---|---:|---:|
| T1 单位变换 | 0.0 | ≤1.2e-5 |
| T2 已知平移 | 7.1e-15 | ≤1.2e-5 |
| T3 一般旋转（非单轴） | 7.1e-15 | — |
| T4 混合 6DoF | 7.1e-15 | ≤1.2e-5 |
| T5 `H⁻¹(H T) = T` | 7.1e-15 | ≤1.2e-5 |
| T6 004 侧 H / 005 侧 H⁻¹ | 7.1e-15 | — |

"端到端损失等价" = 在相机 `T₀` 上传入增量 `H_in` 与在相机 `H_in T₀` 上传入单位矩阵，
两者 M/I/C/O **实际损失值**之差（float32 光栅化上限约 1e-5）。

## 旧错误的可检测性

同一测试里显式复现旧写法（把 `H@T` 当增量传入）：I 从 0.1001 变到 >0.15（差 >0.05），
说明该断言确实能抓住 D2，而不是恒真。

`canonical_np` 与历史 `canonical()` 逐位一致（max diff 0.0）。
