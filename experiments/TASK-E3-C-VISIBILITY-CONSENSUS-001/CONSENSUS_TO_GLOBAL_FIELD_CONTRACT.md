## 几何与证据是独立对象

原始几何位置、拓扑与全部461,023张面永远保留。本轮仅对53,615张采样面的**重心**附加证据；未采样407,408张面为UNASSESSED，不能继承最近采样点的正确/错误标签。即使标为FREE_SPACE_CONFLICT，面也不被删除或移动。标签不是深度预测，不是统一表面，不改变原生HERO。

每项证据必须携带 `source_id, original_face_id, candidate_id, XYZ_mm, normal, source_family, parent_RGB_SHA, frozen_camera_SHA, Mask/CAD身份, τ定义, observer_id, admissibility, reason_bits`。逐观察源压缩CSV是完整证据表，候选摘要CSV不能替代它。原始计数、相关性归一响应、有效/未知观察源数和严格上游链标志均独立保留。

类别为 MULTI_SUPPORTED / SINGLE_SUPPORTED_UNVERIFIED / FREE_SPACE_CONFLICT / CAD_OCCLUDED / CORRESPONDENCE_UNRESOLVED / UNKNOWN；`physical_truth`始终UNRESOLVED。MULTI表示多个来源响应，不代表独立样本或物理同一性认证。来源自身不是外部支持票。无法判定时允许弃权，不能强迫产生正确/错误二分标签。

## 三种数值不能互换

B0为源相机轴向差 `D_native(pi(X))-z(X)`；B1为到原开放Mesh的UDF或有条件局部有向距离。二者都不是已认证的完整物体SDF。Support核使用轴向误差窗，不对B0和UDF取平均；Raw UDF只作几何邻近资格，原面法向只提供局部相容代理。

候选A轴向半宽 `τ_A=max(.25mm,3z_A/f_A)`；其射线方向 `r_A=(X-c_A)/z_A` 不单位化。在观察源B相机中传播为 `τ_A→B=|r_A dot R_B[:,2]| τ_A`，联合观察误差窗采用 `τ_pair=τ_B+τ_A→B`，不假定独立高斯误差而使用RSS。宽度是冻结工程容差，不是校准标准差、置信区间或毫米精度证明。

Support为 `exp(-.5*(delta/τ_pair)^2)`；遮挡/自由空间连续响应为相反方向的sigmoid。区间分离才计数冲突；连续响应本身不等于合法反对票。字段 `S/O/F_numeric`、最低资格、V3强资格和原始/相关性总响应必须保留，不得只传最高分或单一标签。

## 可采纳的自由空间代理

所有版本均要求冻结参考相机筛查、合法投影/ROI、Polyp Mask、有限正原生深度、查询点和源首深度没有CAD次序矛盾。CAD后方、无深度、非同物体Mask、未知视角不产生不存在负票；不假设ROI入口在息肉外部。

V3还要求：原生和Raw首交对前方分离达成一致，源与观察源的原生/Raw差异在冻结容差内，观察射线首原面位于CAD之前、局部法向/连通/掠视与Mask/Ring边缘条件合格，并保留起源自身的合法可见性。所有这些条件仍只有**几何代理**资格；参考相机筛查与上游非候选链不是绝对位姿GT。严格链代理和普通条件链必须分列。

本轮V2的28,137条候选—观察源自由空间代理中，2,939条仅原生判前方而Raw不判前方，其中737条有有限Raw首交，2,202条没有Raw首交。后者可能只是开放Mesh缺面，不能都归因于重采样误差。V3全部未采纳这些代理；合计6,484条因各强门槛未获V3资格。不能把拒绝数叫“纠正的真实误检数”，也不能把剩余21,653条叫真实错误面。

## 单来源、相关性和遮挡

同视频实际HERO父图像Jaccard决定固定依赖代理权重：`w_j=1/(1+J(A,j)+sum_k J(j,k))`；上游仍有候选相机时再乘0.5的未校准排序代理。归一票质量不是独立样本量、正确概率或显著性证据。共享父图像不抹除独有几何；所有独有面保留。

位于他源首深度后方只表明可能被前层遮挡，不证明后面不存在或属于同一物理面。原始HERO多层和不同可见曲面的物理身份仍待确认。不存在第二视角不是反对票；SINGLE_SUPPORTED_UNVERIFIED可以长期合法存在。未知/遮挡不能变成正SDF、背景或inside。

## 多峰深度窗口

同一真实观察源射线上的原候选深度、观察源原生深度、各原始Mesh的首次交点均按来源分别保存。局部平面误差向射线轴向区间传播采用 `τ_i*|n_i·r_i|/|n_i·r_B|`；掠视或不可界定时保持不定。区间是搜索假设，不是校准深度CI。重叠区间和分离区间都不能压成平均深度，不选单峰，不生成第三层。

只记录每Mesh首次射线交点加起源原面候选，**不是穷尽每Mesh的所有背层**。所有原面仍存在，未枚举的层不是被否定。搜索窗口受原冻结ROI约束；区间/来源/遮挡资格不能丢失。16条有限真实射线、64个来源标记模式只是合同验证，不是全部体积的认证。
