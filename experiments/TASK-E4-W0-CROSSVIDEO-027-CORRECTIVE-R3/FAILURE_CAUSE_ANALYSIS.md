# FAILURE_CAUSE_ANALYSIS（R2 的 12° 失败）

按任务要求的顺序排查：

1. **GT 能否满足观测？** 能：Level 0 残差 RGB 0、I/C/O ≤1.2e-13（R2 已证，本轮沿用）。
2. **三角化初值是否正确？** **R2 的初值错误**：用 `H=I` 的 004 相机把 004 观测三角化进 005 世界，
   地标系统性偏移（R2 `X_init_err` 0.8–6.5 mm）。本轮改为 **005-only 三角化**（正确坐标系），
   地标初值误差仅 3.8e-14 mm。
3. **变量集合是否正确？** 本轮实测：H-only 参数 **6** 个（rank 6/6）。
4. **Jacobian 是否正确？** 秩满、条件数 45–47；方向导数相对误差 0.54 来自最近边切换的折点（已记录），
   在 GT 附近残差 rms 1.1e-8、梯度 3.4e-7，不影响收敛。
5. **是否可辨识？** H-only 在 0–18° 全部可辨识（rank 6/6）。
6. **是否收敛？** 0°/1°/3°/12° `success=True`；6°/18° 达 200 次上限但几何误差 ≤1.2e-3°。

## 直接对照（同一 12° 场景）

| 实验 | 结果 |
|---|---|
| H-only（地标冻结，正确坐标系初值） | **3.8e-04°** |
| 联合（正确坐标系初值） | 0.0073° |
| R2 联合（错误坐标系初值，40 次） | 7.06° |
| R2 联合（错误坐标系初值，400 次） | 3.04° |

⇒ **主因是地标初值（坐标系错误）+ 联合自由度，不是 Ring、不是鲁棒尺度、不是可见边缘。**
