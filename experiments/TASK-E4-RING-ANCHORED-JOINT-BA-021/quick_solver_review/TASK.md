# 三、Task A：成熟求解器快速复核021 BA

## A1. 继承021现有数学目标

直接复用：

- `code/ba021.py`
- `config/PROTOCOL.json`
- 18条共同SIFT轨迹；
- 553个FIT二维观测；
- 021冻结的B1/B2/B3终点；
- Ring CAD和现有多曲线约束。

保持原有优化参数定义：

\[
\theta=
\left\{
T_{004\leftarrow005},
X_1,\ldots,X_{18}
\right\}
\]

其中：

- \(T\)：video005相对于video004的共享SE(3)；
- \(X_k\)：两段视频共同观察的三维SIFT地标。

本阶段**不加入三张独立照片**，避免在更换求解器时同时改变观测集合，破坏因果对照。

## A2. 采用成熟求解器

优先使用：

- SciPy L-BFGS-B；
- 或PyTorch LBFGS；
- 必要时使用成熟的信赖域最小二乘方法。

选择一个能够正确复用021原始损失函数的求解器即可。

本轮不开发新的BA框架。

首先验证：

1. 原始021损失数值能否准确复现；
2. 自动微分梯度是否正确；
3. 有限差分与解析梯度是否一致；
4. Ring可微渲染是否存在数值不连续；
5. 原有SE(3)、地标约束是否有效执行。

如果原021目标存在实现问题，必须单独报告，不能静默修改后仍宣称是同一目标函数。

## A3. 最小优化实验

| 实验 | 初值 | 优化变量 |
|---|---|---|
| A0 | 021冻结B1/B2/B3 | 不更新 |
| A1 | 021 B1终点 | 共享SE(3) |
| **A2** | **021 B2终点** | **共享SE(3)＋共同地标** |
| A3 | 021 B3终点 | 共享SE(3)＋共同地标 |

A2是主要实验。

所有输入、权重、物理约束和FIT观测保持不变。

若优化器确实突破停滞，可进一步从RoMa原始初值进行一次简短复核。

不重新运行360°搜索，不重新提取全部SIFT，不重新进行大规模匹配。

## A4. 评价

必须比较：

- 原始目标函数；
- 梯度范数；
- 优化收敛；
- 实际SE(3)变化；
- 地标移动；
- Ring Mask及Inner/Outer误差；
- 正反向SIFT重投影；
- FIT/HOLDOUT轮廓；
- 独立HERO共同可见一致性；
- 固定观测集合中的毫米级残差。

HOLDOUT、HERO和主体不得进入本阶段优化目标。

候选先冻结，再进行独立评价。

最终回答：

**021的停滞是求解器问题，还是现有观测本身已经不足以支持更好的共享位姿？**

## B2. 三张照片必须独立建立相机位姿

**独立照片不能继承video004或video005中某一帧的相机外参。**

因为它们来自额外拍摄。

每张照片都需要恢复自己的独立位姿：

\[
T_{\mathrm{photo},i}\in SE(3)
\]

建议按以下流程实现：

### 第一步：Ring-First初始化

使用：

- 真实Ring Mask；
- Inner/Outer可见弧；
- Mid中心线；
- 已知Ring CAD；
- 相机内参。

得到照片相对于Ring的公制位姿候选。

严格考虑Ring绕法向的旋转对称性。

Ring单独不能唯一确定完整空间方向。

### 第二步：RGB特征补充方向

利用真实RGB进行SIFT匹配。

将独立照片与video004、video005中具有有效特征支持的视角匹配。

优先复用现有020/021的SIFT、三角化和PnP组件。

对于照片中可对应到已知公制地标的特征，使用2D–3D重投影约束。

对于仅有2D–2D对应的情况，保留相应几何证据，不能假装已经得到精确三维位置。

### 第三步：Ring约束下的位姿精修

使用：

\[
\boxed{
L_{\mathrm{photoPose}}
=
\lambda_RL_{\mathrm{Ring}}
+
\lambda_FL_{\mathrm{SIFT}}
+
\lambda_PL_{\mathrm{posePrior}}
}
\]

照片位姿应单独优化。

不允许将三张照片视为一段具有已知相对轨迹的短视频。

不使用018主体作为主要照片位姿优化依据。

主体只用于冻结后的独立投影评价。

### 第四步：统一公制坐标

所有照片最终需要转换到G01的统一Ring-First世界坐标中。

保留：

- 原始照片；
- 原始位姿候选；
- Ring初始化位姿；
- SIFT精修位姿；
- 坐标变换链；
- 实际重投影误差；
- 仍无法确定的旋转歧义。

如果一张照片存在多个不能可靠区分的合法位姿候选，应保留候选并报告，不得制造唯一正确位姿。

但不得以历史Ring拟合失败为由，放弃后续成熟方法恢复尝试。

# 五、三张照片的HERO准备

我们最终希望利用照片提供新的三维观察方向，而不只是二维Mask。

因此，对获得合理公制位姿的独立照片，需要进一步检查其HERO输入。

## C1. 是否存在已有原生HERO？

逐张核对：

- 原生HERO深度；
- 目标RGB身份；
- 推理时使用的相机；
- 支持视角；
- 原始输出分辨率；
- 公制坐标；
- 原生HERO Mesh。

不得把其他视频帧的HERO投影过去，冒充照片的原生HERO。

## C2. 缺失时优先重新运行官方HERO

如果照片具有有效相机和真实图像，但没有对应的合格原生HERO：

优先复用018已经验证的官方MVSAnywhere推理流程。

以独立照片作为目标视角。

支持视角从同一测量组中选择，并确保使用一致的派生相机坐标、正确RGB与真实图像身份。

不使用GT。

不修改HERO模型权重。

如果照片相机尚有重大歧义，不能强行生成并宣称得到具有可靠公制坐标的HERO。

## C3. 使用017标准完成可信度清理

对新生成或尚未清理的照片HERO，执行017已有清理流程。

首轮监督规则：

| 类别 | 是否参与后续主体适配 |
|---|---|
| TRUSTED | 是 |
| UNCERTAIN | 暂不作为强约束 |
| UNKNOWN | 否 |
| REJECTED | 否 |

必须导出真正的TRUSTED面片子集。

保留原始HERO深度、面片和像素对应。

不需要重新开展大规模可信度分类研究。

这部分以复用成熟流程为主。

# 六、评估三张照片的实际新增价值

不能仅仅因为多了三张照片，就认为三维重建一定改善。

要计算它们实际补充了多少新的观察信息。

对每张照片分别报告：

1. Ring重投影误差；
2. Inner/Outer边界误差；
3. SIFT有效对应数量；
4. 位姿稳定性；
5. 与已有相机的观察方向差异；
6. TRUSTED HERO面积；
7. 可信HERO与已有来源的相容性；
8. 相对于现有主体的深度残差；
9. 主体当前未覆盖的可信HERO比例；
10. 相对于现有视频视角的新增可见表面。

重点判断：

**三张独立照片是否能够补充video004/005此前缺乏的观察方向。**

如果某张照片观察到此前未覆盖的真实Polyp表面，即使它与现有视频的共同SIFT点很少，也可能具有很大的后续重建价值。

不应仅根据SIFT匹配数量判断照片是否有用。
