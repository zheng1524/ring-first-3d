# 四、核心算法：Ring＋SIFT几何位姿精修

## 4.1 优化变量

对现有相机初值：

\[
T_i^{(0)}\in SE(3)
\]

定义：

\[
\boxed{
T_i(\delta\xi_i)
=
\exp(\widehat{\delta\xi_i})T_i^{(0)}
}
\]

其中：

\[
\delta\xi_i\in\mathbb R^6
\]

注意坐标约定：

- 使用OpenCV camera-to-world作为统一存储；
- 优化时统一处理world-to-camera投影；
- 毫米为公制单位；
- 保持相机内参来源；
- 不释放尺度。

必须明确左乘扰动对应的坐标系。

四组分别建立各自的固定Ring公制世界坐标，不能把不同息肉组的相机放入同一个物理场景。

## 4.2 Ring几何损失

不得继续依赖021未经验证的PyTorch3D Ring软光栅化梯度作为主要优化方向。

使用真实三维Ring CAD及可见Inner/Outer构建几何残差：

\[
\boxed{
L_R=
L_{\mathrm{Inner}}
+
L_{\mathrm{Outer}}
}
\]

对于可见的观测边界点：

\[
r_k=
\frac{
d\left(
u_k,\Gamma_{\mathrm{CAD}}(T)
\right)
}{
\sigma_k
}
\]

必须做到：

- Inner和Outer保留不同物理边界身份；
- Ring的圆形线材厚度得到正确处理；
- 使用真实CAD可见轮廓；
- 不把完整拟合椭圆视为全部真实可见弧；
- 排除真实Polyp遮挡区域的虚假边界；
- 不要求Ring提供不存在的yaw信息。

Mid继续作为独立几何诊断。

Ring Mask用于评价，也可作为经过单独验证的辅助约束；不得通过原有错误梯度重新引入问题。

## 4.3 RGB特征约束

优先使用真实SIFT对应：

\[
\boxed{
r_{ij}
=
\pi(K_iT_i^{-1}X_j)-u_{ij}
}
\]

对于已有可靠三维地标的观测，使用2D–3D重投影。

对于没有可靠三维地标、但具有真实跨视角RGB对应的情况，使用合适的2D–2D几何约束或合法的联合三角化。

不能通过三维最近点距离制造SIFT身份。

应检查：

- SIFT匹配数量；
- 多视角轨迹；
- 三角化视差；
- 重投影误差；
- 特征空间分布；
- 离群对应；
- 几何可辨识性。

不同视频、不同视角和不同轨迹的重复观测需合理归一化。

## 4.4 联合损失

优先采用：

\[
\boxed{
L=
L_{\mathrm{SIFT}}
+
\lambda_R L_{\mathrm{Ring}}
+
\lambda_P L_{\mathrm{prior}}
}
\]

位姿先验用于约束相机不要产生无依据的大幅漂移。

相机更新必须与实际Ring几何、SIFT及静态场景假设一致。

**不把主体或HERO加入位姿优化损失。**

它们只能用于候选冻结后的独立评价。

# 五、雅可比验证是正式优化的必要条件

021已经发现：

\[
\nabla L_{\mathrm{Ring}}^{AD}
\not\approx
\nabla L_{\mathrm{Ring}}^{FD}
\]

因此，新方法必须首先验证实际几何残差的雅可比。

对六个SE(3)自由度分别进行：

- 解析/自动微分；
- 中心有限差分；
- 多步长对照；
- 实际目标变化检查。

必须分别验证：

- Ring Inner；
- Ring Outer；
- SIFT重投影；
- 位姿先验；
- 完整联合目标。

如果可见性或最近曲线对应存在切换，应采用局部固定对应、重线性化及真实目标检查，不能把不连续性误认为可用梯度。

最终确认：

\[
J_{\mathrm{implemented}}
\approx
J_{\mathrm{finite-difference}}
\]

且实际更新能在信赖域机制下正确接受或拒绝。

**如果雅可比仍然存在明显错误，本轮在此停止。不得继续运行四组大规模优化。**

## 最终科研目标

本轮最重要的不是让某一张图的Ring更加贴合，也不是单独提高G01的一个指标。

而是建立并验证：

**一套真正可以在不同息肉形态、不同观察方向和不同原始相机条件下运行的几何位姿精修方法。**

如果它在四组现有视频中表现可靠，我们才有充分理由进一步把12张独立照片加入相同的几何体系。

如果四组实验已经暴露方法上的关键问题，就及时停止，用真实失败证据指导下一轮研究，而不是继续扩大输入规模。
