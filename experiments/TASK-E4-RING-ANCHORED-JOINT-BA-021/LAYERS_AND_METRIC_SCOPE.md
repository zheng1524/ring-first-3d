# 四组真实几何图层与评价口径

每个GLB位于 `derived/Gxx/Gxx_INDEPENDENT_LAYERS_NOT_FUSION.glb`。各几何对象可在支持场景树的GLB查看器中单独开关；这是原生曲面叠加场景，不是融合Mesh。

| 图层节点 | 身份与使用方法 |
| --- | --- |
| `Ring_CAD_FIXED` | 黑色固定真实CAD实体，不是重建点云 |
| `BODY_B0_INFERRED_CAP_GRAY` | 018冻结初始主体；灰底盖为推断，不是已观测组织 |
| `BODY_B2_INFERRED_CAP_GRAY` | 018冻结HERO适配主体；与B0分别打开比较 |
| `HERO_<Source ID>` | 每个原生TRUSTED来源独立对象、独立颜色；所有原面保留，不补洞、不ICP |
| `CAMERA_<View ID>` | 冻结相机的实际位置/方向和1mm轴向深度标定视锥 |
| `TRAJECTORY_<video>_<segment>` | 按已核验的原始帧绑定顺序连接；不是新估计的轨迹 |
| `BACKGROUND_BASE_ESTIMATE_*_NOT_GT` | 如存在，为历史背景拟合平面，不是Ring平面或基底GT |
| `COMMON_SIFT_B3_NOT_HERO` | 仅G01，021共享地标，不是HERO曲面 |

GLB按规范用米导出：mm坐标乘固定0.001。恢复毫米只需乘1000；不是尺度拟合。源文件路径、SHA、原始Face ID数组SHA、图层颜色与相机K/c2w见每组 `SOURCE_LAYER_INDEX.json`。全部三维指标在毫米坐标中计算。

G01展示021事前指定B3派生005坐标，另保留RoMa/020R3/021的同视角对照。G03/G05/G06核心场景仅为018既定video004来源，不能称跨视频配准。核心审计相机集合为G01的020全部68视角、其余三组018的9/11/10视角；其他014缓存帧仅在轻量资产清点中登记，未静默冒充新的已认证相机/HERO来源。

- 六视角中每行各方法共享同一个真实相机或展示相机、范围与尺度。自由展示相机不参与拟合和评价。
- 2mm比例尺标在观察中心深度；透视画面不同深度的局部像素尺度不同，不是正交投影承诺。
- 多HERO旧可比较误差包括单列的后方观测，仅为020兼容诊断；后方可由正常自遮挡解释，不能直接称错误双层。
- 首层共同可见候选进一步检查源自身CAD次序，并排除后方；仍是未校准可见性代理，不是真实共表面GT。
- 原生HERO到主体的有效首层误差与固定原始分母、未命中、CAD遮挡/Unknown、共同/新增/丢失命中必须同时读。未命中不填充深度。
- 累计来源三角面面积不是唯一解剖面积；0.25mm面心占据格并集不是解剖面积/体积测量。
- 红色前方分歧为几何代理；灰色Unknown不是零误差。TRUSTED是017冻结资格，021不擅自重新认证或删面。
- CAD双向有限采样、独立FCL相交和自交检查互补；采样为零不等于严格实体无穿透证书。

绝对部署相机/形状精度 `NOT_EVALUABLE`。无项目GT、无局部ICP、无Dxy历史值补齐；所有旧失败保留。
