# 四、统一数学模型

对于需要CAD精修的方案：

\[
\boxed{
L(T)=
\lambda_RL_{\mathrm{Inner/Outer}}
+\lambda_FL_{\mathrm{SIFT}}
+\lambda_PL_{\mathrm{prior}}
}
\]

其中：

\[
L_{\mathrm{Inner/Outer}}
=
\sum_{k\in\{I,O\}}
\sum_{u\in\Omega_k}
w_u\rho\left(
d(u,\Gamma_k^{CAD}(T))
\right)
\]

\[
L_{\mathrm{SIFT}}
=
\sum_j
\rho\left(
\|\pi(TX_j)-u_j\|
\right)
\]

要求：

- 完整Ring CAD尺寸固定；
- Inner与Outer身份固定；
- 只使用真实可见弧；
- Polyp遮挡区域不得虚构Ring边界；
- 不使用HERO和主体参与位姿拟合；
- 相机尺度固定为公制；
- 所有优化结果保留原始相机作为独立对照。

对于Mid椭圆：

优先用于Conics位姿初始化。

若需要作为额外损失，必须先证明其误差模型合理，并与Inner/Outer的相关信息去重。
