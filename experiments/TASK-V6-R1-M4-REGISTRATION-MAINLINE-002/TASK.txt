一、背景、目标与执行原则

用户已经观察并认可 TASK-V6-R1-CROSS-VIDEO-REGISTRATION-001 的效果，现决定以其中的 M4 为跨视频配准主线，不再研究其他配准方法。HERO 的 R1 全量执行已由用户确认完成。下一轮的任务是：在现有 M4 内减少少量异常对整体变换的干扰，并将其整理成可消费全量 R1 产物、可交给共同主体阶段的统一流程。

上一轮六组、12 视频、221 个 HERO 来源是回归资产，不是本轮的全量范围。IIa14/R5 已表现出较一致的改善；IIa14/R10 的大均值包含少量极端观测；Ip8.8/R5 提醒我们曲面距离与 RGB/Ring 证据可能冲突。这些现象用于理解问题，不作为按组写特殊算法的依据。

工程效果优先。本文说明设计意图、必要边界与应交付的结果，不要求把每个诊断建议都做成独立模块、硬门槛或大规模实验。具体匹配整理、稳健权重、数值处理、参考视频选择、代码组织和图表形式由你根据已有实现裁量。优先一个小而明确的修正，及时收敛到一套通用配置。

本轮只推进 M4 配准及其输入输出。M5 与更早方案保留历史记录，退出常规运行；原 M4 只作为修正前的工程回归参照。共同主体接口做到可消费，本轮不展开主体拟合、主体更新或新的融合算法。

三、保持主线的核心含义

M4 继续使用已有 Ring-First 相机与跨视频 RGB 对应；在视频内独立三角化后，用三维地标约束和独立 Ring 先验估计视频级刚体变换。可以充分使用共同背景纹理，不要求息肉区域特征达到某个比例。

每个视频只有一个公制 T_v，尺度为 1。相机、地标和 HERO 同步转换一次：
   C_global = T_v @ C_local
   X_global = T_v @ X_local
参考视频定义本组共同坐标，CAD 在共同坐标中固定。沿用现有 K、轴向深度和 native 到 mesh 的像素映射约定。保持 Ring 独立二次先验，不把它再次交给 RGB 的全局鲁棒核压平；调整 RGB 权重或有效轨迹数时，说明归一化，避免意外改变 RGB 与 Ring 的相对强度。

原始视频、Mask、相机解、HERO 深度/Raw 网格及上游运行记录只读；本轮不重新运行上游大模型、相机恢复或 HERO。也不通过逐帧位姿自由度、尺度变化、非刚性变形或新增曲面配准路线吸收残差。

可信 Clean 继续使用已认可的 017+gap 分类与 018 TRUSTED-only：仅保留原 F[state==0]。先确定并冻结本轮 M4 的 T，再将曲面和对应相机放入共同坐标、相对固定 CAD 分类。Clean 不参与本轮 T 的拟合或择优；共同保留面不产生额外形变。

四、小幅修正：减少异常的实际影响，而不是美化均值

先用已有 FIT 数据做一个简短诊断，分清两类情况：
   A. 错误或不稳定的拟合轨迹确实拖动了 T。
   B. T 已较合理，少数评价轨迹的误匹配/独立 DLT 异常主要拉高了报告均值。
IIa14/R10 的 held 极端误差本身不能证明 A。优先检查 FIT 轨迹可靠性、残差、空间分布及少量高影响轨迹的去除/降权影响，无需逐轨迹穷举或完整统计研究。

若确有 A，在现有 M4 内做改动最少的通用修正。可以采用轨迹可靠性限权、去重归一化或简短稳健重估等思路，但不指定你必须选哪一种；解释为什么它能抑制异常、如何避免丢掉有效约束。允许根据每组 FIT 数据按同一规则估计尺度或权重；不写按组名、形态或结果好坏切换的参数表。

保留原来的整轨迹 FIT/held 区分。用于实际求 T 的筛选、权重和自适应参数只读 FIT；held 观测及其失效记录仍完整保留。不能通过删除 held 的坏点、只报一个方向或按 held 为每组挑选旧/新 T 来制造收益。

原六组已被研究者看过，明确作为开发回归，可用于判断这次统一修正的工程收益，不包装成新盲测。回归尽量沿用原参考、轨迹划分和评价域，隔离稳健性修改本身；必须变化时说明比较口径。保留修正前后同域结果，说明 T 是否改变、好组有没有受损、困难组改善来自哪里。若诊断表明原稳健机制已足够，或新修正没有实际收益，允许全局保留原 M4 并如实说明；本轮仍应完成统一入口和全量接入，不为了“必须修改算法”而硬加复杂度。

最终全量只采用一个明确的 M4 版本和一套通用规则。版本确定后再运行新增组；运行中若发现工程错误，修复后按同一规则重跑受影响阶段并记录版本变化。不要扩展成持续的方法搜索。已有必要的坐标与数值回归可以复用；无需重新启动一轮完整虚拟研究。

2. 去掉 audit.py 中 CFG['group_names'] 的六组限制和 sorted(videos)[:2] 的截断。纳入每组所有可用视频及其全部合法 HERO 来源，不能因为不是 004/005 或不在旧冻结名单中拒绝。全量指全部现成资产接入，不要求把所有原始帧放入全连接 SIFT；沿用或合理整理已有代表帧策略，控制匹配预算。

3. 每组明确一个共同参考视频。按统一的数据可用性/重叠规则选择，不能根据 held 或曲面效果挑参考。其他视频调用同一 M4 得到 T_v→reference。直接重叠不足时，允许仍用 M4 经有重叠的已连接视频中转，记录组合路径；不必为此增加全局优化。不能连通的视频保留为未接入或独立分量，不能以单位阵冒充成功配准。
   多视频/中转时，共享轨迹的 FIT/held 身份在组内保持一致。同一原图特征或连通轨迹若已在其他求解边使用，应明确标为已用观测，不能再作为独立留出证据；完整观测与计数仍保留。

4. 统一 M4 贯穿所有阶段，而不只是改 predict.py：
   - clean_after.py 改为消费 M4 的 T；
   - evaluate.py 为 M4 计算 clean 并附正确 selection；
   - visualize.py、deliver.py、相机/地标导出和组接口统一指向 M4；

   具体代码结构由你决定，不要求保留旧脚本边界。

5. 按阶段复用缓存。输入与实现未变的特征、轨迹、DLT 可以沿用；M4 求解行为或配置改变时重新求 T。Clean 的复用还要匹配具体 T、原始来源、参考 CAD 和分类版本。旧 M5 的 B 侧标签不能直接改名当 M4 标签；同输入、同坐标的 A 侧及已有 IIa14/R5 M4 结果可在核验后复用。不能只因文件存在就跳过，也无需把所有阶段一律重算。

六、输出可供主体消费的统一资产

每组形成一个稳定入口，至少能查到：
   - 全部视频、参考视频、连通状态及每视频 T；必要时有中转路径。
   - 公制单位、变换约定、全视频相机与地标；明确哪些已处于共同坐标，防止再次应用 T。
   - 原 HERO 来源及身份、真实 case/Target/Support、所属视频、应应用的 T。
   - 与本轮 M4 坐标对应的可信原面 ID/selection、Clean 来源与状态。

优先用“原资产引用＋T＋可信面索引”，不必复制全部网格。每个来源在组接口中只登记一次；不同视频相同 tag 不能误当同一个来源。未接入共同参考的来源仍可保留，但下游必须能区分。

用一个轻量读取/渲染检查证明接口能实际恢复共同坐标下的相机和可信面；不要求在此轮实现主体优化。下游应只消费这一入口，无需猜测旧目录、M4/M5 标识或 candidate 特例。

七、评价与可视化：围绕工程效果，保留真实问题

原六组给一张“旧 M4→本轮 M4”的简表；全量给一张统一状态与效果表。沿用已有评价，不另建庞大指标体系。至少让读者看清双向图像误差的均值/中位数与尾部、有效与失效数量、Ring 一致性和 Raw 曲面表现。不同方法/版本有限观测集合若变化，同时提供共同观测上的辅助比较；不要只比较各自筛剩的好点。

曲面比较沿用固定原始来源及原面采样，不因 Clean 或效果变化重选更好区域。Raw/Clean 使用各自已确定的同一个 T，清理仅改变保留面；删面带来的整洁和覆盖变化单独解释，不算作位姿精度提高。

中文图集以三种状态为主：配准前 Raw、M4 配准后 Raw、M4 配准后可信 Clean。每组使用相同视角与尺度；保留真实截面、适量 RGB/Ring 投影和相机布局。图中标清视频颜色、来源数量及失效/越界计数；原始离群面与缺面可见，近景不能替代完整范围。不必再输出多种方法的比较大矩阵。

报告展示代表性的好转、基本不变和仍有问题的情况，不要求每个组每项指标都单调变好。少量异常和某个偏大的均值不自动成为整组硬拒绝条件；结合现有证据给出“可供下游试用 / 需留意的问题 / 暂未接入”的简明说明。没有三维 GT 的组，称跨视频一致性，不声称绝对重建精度。
