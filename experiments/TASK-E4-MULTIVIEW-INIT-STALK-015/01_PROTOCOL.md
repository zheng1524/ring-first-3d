# Multi-view Initialization + Stalk｜运行前算法合同

正式范围：013/014权威CASE_LOCK的11个独立组（G01–G11）；Ip为G01/G02/G03/G10/G11，Is为G07/G04/G05，IIa为G06/G08/G09。历史资格只作诊断。G08使用原参考视频005，其余004；无跨视频相机修正。所有相机、RGB/Mask、CAD和原生HERO只读。

Phase A所有组比较：

- Init-A：逐字节继承013冻结INITIAL（原九例011 FINAL；G10/G11为013中的配方等效011 FINAL）。元数据中的旧初始化描述为祖先信息，不代表该Mesh未经过011优化。
- Init-B：对同一实际Mesh进行六参数变换，由同视频多视角联合拟合。封闭模型为三平移+三轴尺度；有推断底盖的主体为基底内两平移+三轴尺度+基底内旋转，保留基底半空间。此处不冒称重新拟合解析椭球。
- Init-C：读取011的真实C参数及家族，使用原`parametric.body`公式（椭球/有界星凸/有限支撑冠面），重新拟合其真实参数。家族来自冻结的接触与基底证据，非根据GT或类型临时换模型。底盖不进入渲染和深度射线。

选择8个同视频FIT：保留原013 FIT；其余按方向最远距离加固定图像质量项选择。方向0.65、清晰度0.10、Mask边界完整性0.10、二维细结构可见代理0.10、Ring非占据比例0.05，各质量项组内归一。细结构代理为原Mask的形态骨架，不能认作真实三维柄。原013与同视频014留出均保护，只称本轮几何更新留出，上游资产未必独立。

Init-B/C复用011的SciPy TRF、固定中心差分、前景/背景归一的Ring-Aware软轮廓、同视角相对深度、边界降权弱绝对深度、公制CAD距离与反向包含惩罚及弱参数先验。20次nfev，无参数搜索；最后求解结果即产物。另从同一原始参数以删除最后一个新增FIT视角的子集拟合8次nfev，作为有限稳定性诊断，不参与选结果。不能将nfev预算耗尽自动叫做收敛。

三种初始化后均执行完全相同的014成熟`MultiObjective(D0_013)`与自由顶点优化：原013的A3轮廓/FN/FP/双向距离系数，014的按HERO来源独立归一和方向均衡；绝对/相对深度系数各0.01，形状保护为原边长+Laplacian+0.01法向+0.01未观测位移。不使用跨视角HERO一致性损失。Adam lr0.02、旧四个归一化局部方向、8级半步回缩、精确参数和动量回滚。统一80候选/40接受/30连续拒绝预算，源于014快速臂；本轮没有用户要求的更长迭代指标。

每个候选复用014的32阶三角面内部CAD采样、FCL、反向包含、Open3D非邻接自交、面片朝向/面积和基底检查，最终另做64阶审计。不以取消Ring保护换改善；初始已有碰撞单独记录，要求不恶化，有限采样不等于连续空间证明。不同初值的网格、拓扑密度和数据依赖可见先验差异明确报告。

Phase A全组完成后以预定FIT规则选择一个全组主线：每组`1−IoU +0.02×固定分母深度代价`，取11组中位数；若新增Ring/自交失败组数多于Init-A则不入选；并列按A/B/C顺序。留出与GT不参与。输入数值缺失为失败，不补用其他路线预测。

Phase B仅5例Ip，从同一已选Phase A FINAL开始：Stalk-A复用当前自由顶点候选；Stalk-B使用轮廓残差实际关联顶点扩大候选覆盖；Stalk-C实际中心线/长度/方向/沿线半径参数加局部自由残差。三者保留相同观测、损失、总预算和CAD保护。具体表达、变量及梯度检查在Phase B任何更新前另存合同与冻结哈希；不把顶点子集或单一尺度更新冒称中心线模型。

GT只在所有预测及尺度冻结后打开。主要三维指标要求独立的固定GT→Ring变换；若缺失则标为`NOT_EVALUABLE_UNREGISTERED_GT`。作者原坐标中的未对齐距离只作显式坐标诊断，不能称物理精度。每预测最佳SE3如计算，仅放补充诊断，不能代替主要未对齐评价，也不调尺度。F-score阈值0.1/0.25/0.5/1mm、固定面积采样8192/方向；Dxy沿作者参考轴，基底不可靠的高度不输出假值。B0按章程逐组给出，不将数值成功当作物理认证。

Phase C仅当真实病例无法区分原因时，采用现有虚拟场景进行一个预先声明的理想Mask控制，不增加额外方法或大规模扰动。
