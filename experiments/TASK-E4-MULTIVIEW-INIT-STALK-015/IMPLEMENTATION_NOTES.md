# 实现与预注册差异的主动披露

- `config/PROTOCOL.json`中的通用seed字段为20261109；实际继承训练脚本对torch/NumPy统一固定为20261108，所有初始化和柄部对照相同。保留原协议及实际源码，不在运行中静默改seed。TRF是确定性求解；实际运行seed以每个完整checkpoint的随机状态为准。
- 最新人工指令明确允许逐预测最佳六自由度ICP。本轮原协议的未对齐主要评价限制由独立追加文件覆盖，历史协议和章程原文不回写。
- Init-B是当前真实冻结网格的多视角六参数变换；闭合主体是XYZ+三轴尺度，截断主体为基底平面内位置/尺度及平面内旋转，以保持底界。Init-C复用现有011参数化模型族，而非从GT取形状。两种初始化自由度不同是策略对照的一部分，不冒称完全隔离表达能力。
- 所有下游统一复用014 `MultiObjective D0_013`：013的轮廓/FN/FP/距离系数，014按方向分区均衡和按HERO来源数归一的深度项。该加载/归一方式与逐字013不同，三种初始化以及三条柄部路线之间保持一致。
- Stalk-C是中心线支持的现有连通片形变，11个明确曲线/截面参数+局部自由残差。它不重新建管、不增顶点、不改拓扑；种子是拟合轮廓的最近投影代理，不是已经验证的解剖头柄分区。
- 预检查曾出现缺失导入、报告生成器语法拼接问题，均在对应正式更新/报告生成前修复；原日志及源哈希保留。没有为修复修改数学目标或科学阈值。独立刚性代数控制和中心线几何控制通过。
