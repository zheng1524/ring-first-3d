# 冻结后形状评价｜人工授权的逐模型 ICP

用户追加授权见 `AMENDMENT_GT_RIGID_EVALUATION.md`，不回写原章程。

所有11组、三种初始化的初始/最终预测，以及5组 Ip 的三条柄部路线，全部冻结后才开放 Blender。每例 Ring 内径 R5=5mm、R10=10mm；当前毫米坐标只做一致性检查，不重复缩放。对每个预测分别沿用014的96个固定正旋转初值+点到点刚性ICP、top8双向最近表面精化，旋转和平移共同变化，scale固定1，禁止镜像/非刚性。搜索不能证明全局最优；保存最优、次优和全部起点。

同一预测的所有指标使用同一个变换。主体ICP不包括Ring、Background。8192个固定种子的面积采样点/方向，查询实际三角曲面距离：双向Chamfer MAE/median/p95/max、独立两方向误差、F-score在0.1/0.25/0.5/1mm。Dxy使用作者基底法向投影Feret；缺少作者基底时使用明确标注的作者坐标轴条件评价，不推断组织基底。Hmax/H95仅在作者基底身份明确时计算。

仅闭合、方向一致、无自交实体才计算Sobol占据估计；推断底盖或不完整GT不能冒充严格实体3D IoU。开放/非法实体仍报告表面F-score，命名为表面重叠代理。不得用占据代理选ICP位姿。

所有形状指标标题统一：`After Ring-based Metric Recovery and Best 6-DoF Rigid Alignment`。对齐后误差不是端到端定位精度。保留未对齐原Mesh与全部固定相机FIT/HOLDOUT投影、HERO固定分母和CAD检查。没有独立GT→Ring坐标标定时，未对齐绝对GT误差为NOT_EVALUABLE，不对坐标原点差直接计算伪精度。

各路线目标分母11组，柄部路线5组。报告独立数值输出数、失败NaN、无历史回退、全部样本分母；尺寸误差含中位绝对相对误差、MAE/p95/max及共同成功组的配对比较。GT不得参与初始化/方案推荐/超参数/终止/模型选择。真实头/柄GT分区若无作者标注，独立柄部Chamfer与长度精度NOT_EVALUABLE，不从预测形状反推GT分区。
