# 不依赖GT的实验观察与解释

## 多视角初始化

11组、三种初始化及相同下游更新全部完成。Init-A/B/C最终FIT IoU中位分别为0.883658/0.899770/0.893749，HOLDOUT为0.879979/0.899133/0.886398。新增视角的联合拟合确实能改善二维解释；不能据此忽略CAD约束。

独立64密集检查显示，Init-B在G03/G07/G05/G06较共同013起点新增采样穿入；Init-C在G03/G07/G06/G10新增。最大新增深度约0.0378mm，并不等于所有穿入都具有同等物理严重程度，但预注册规则不允许据结果放宽门槛。Init-A没有新增标记，因此共同主线冻结为Init-A。

实现机制：初始化TRF使用实际CAD的软惩罚，但仅采样顶点、边中点、三角形中心和部分反向点；不是密集面的硬可行域。后续密集约束以各自初值为基准“不恶化”，不能自动修复已经不合格的初始化。这解释了为什么轮廓更好仍会带入Ring冲突。当前不把B/C静默切换为A，所有失败原模型保留；全组统一推荐规则明确拒绝这两条主线。

## 柄部更新

历史014 G03的239/30已用原始状态和保存梯度独立复算。当前比较使用Phase A后的共享状态和8FIT视角：G01/G02/G03/G10/G11远轮廓关联点为100/20/42/10/0，旧局部带覆盖26/7/0/5/0，扩展后非零候选覆盖100/20/42/10/0。这是观测残差关联代理，不是真实柄部GT标签。

G03 Stalk-B确实生成了突出，但三维图呈片状/三角翼，不能仅凭轮廓覆盖宣布正确长柄。Stalk-C没有恢复明显长柄；其局部参数化片只覆盖42个远残差关联点中的13个，另外29个顶点在该局部表达下没有更新自由度。这个零支持区由参数映射直接决定，不需要读取GT就能验证。Stalk-C的中心线种子来自“当前轮廓轴向深度反投影+加权平均残差方向”，不是可靠三维对应；加入中心线表达并不能自动使种子定位正确。

Stalk-C的G03代理曲线长度由6.5742变为6.4906mm；这是已有片的有效参数轴，不是息肉真实柄长。不得拿它作为柄长测量结果。没有作者头/柄独立语义分区时，真实柄部Chamfer、长度及半径精度必须NOT_EVALUABLE。

G02分量梯度加法相对复核误差0.00038848，未通过原1e-4门槛。全部分量和完整梯度有限；该FAIL保留，不能改阈值包装为通过。误差原因尚未完成数值归因，不将它武断归结于具体库缺陷。

## 选择规则与B0

按事前全组FIT-only规则选出的候选不等于科学上已确认最佳柄部方法。全Mask中位评分受头部和大面积区域主导，可能给没有恢复G03长柄的方案较好分数。必须同时看保存的三维、局部轮廓和几何保护结果，不能仅以这一排序自动升级主线。

目前不能宣布全11组B0通过。尤其G03，候选覆盖提升带来了实际变化，但尚未得到可信的连续三维柄部骨架。Is/IIa不继续做额外柄部更新，保留较稳定主体作为后续人工审核候选。所有实际预测及选择已冻结，不用后来的Blender误差反向筛选输出。

## Phase C 的边界判断

本轮不追加仿真调参。当前关键负结果可由真实残差覆盖、局部参数的严格零支持区及实际三维更新直接定位，足以否定“扩大候选覆盖或增加中心线就必然恢复柄”的说法。拓扑分辨率、可见性和三维对应之间的其余因果分解仍未完全验证，不作已证明的结论；若下一轮需要进一步区分，应先在既有Blender Ip做一个受控的种子定位/可见性实验，而不是无限延长真实病例更新或按GT调整本轮方案。
