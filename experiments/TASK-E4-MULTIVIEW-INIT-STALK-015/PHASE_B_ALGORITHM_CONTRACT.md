# Phase B：实际算法与固定合同

本文件在本轮 Phase B 的任何优化更新之前冻结。11组 Phase A 完成后，以预注册的 FIT-only 全组规则确定一个初始化方法；5个 Ip 均从该方法的 Phase A FINAL 开始，三种 Stalk 方法使用完全相同的起点、8个拟合视角、原 HERO 和受保护留出。不得用 GT 或留出结果挑选初始化、损失或 checkpoint。

## A / B

Stalk-A 是继承的自由顶点 Adam/steepest/四个局部候选方向，物理步长、密集 CAD 检查、实际全拟合目标和状态回滚不变。

Stalk-B 用当前拟合 Mask 的反向轮廓距离 ≥10 原生像素确定关联顶点，扩展两圈网格邻接；优先尝试这些区域实际轮廓梯度的联合方向及最多8个连通区域方向，然后才尝试 A 的候选。每个方向仍必须通过相同完整损失及 CAD/基底/自交检查。这里是投影最近邻代理，不是已经证实的三维柄部。几何候选覆盖与非零梯度覆盖分别计数，不能互相替代。

## C：显式中心线、长度、方向、变截面半径 + 局部自由残差

不生成独立管状模型，不替换网格，不做 GT 柄部分割。在共享的已有网格上，根据拟合视角已知可见轮廓残差 >1px 生成射线代理：采用当前对应轮廓的轴向深度反投影目标像素。Ring 未知区不用于定种子。取误差最高的最多256个代理，加权求扩展方向；现有顶点沿该方向第65百分位定义连接根部，当前剩余跨度定义初始长度。此位置是可审计的残差代理，不保证是解剖柄部。没有有效信号时明确报告 NO_KNOWN_VISIBLE_RESIDUAL_SIGNAL，不转用另一方案结果。

优化变量是11个曲线参数和原网格局部三维残差：根部平移3、切空间方向2、log长度1、弯曲2、三个log截面半径。设原始轴 C0(s)=root+sL0*d0，s为输入网格冻结轴向坐标：

Cp(s)=root+shift+s*L0*exp(l)*normalize(d0+t1*e1+t2*e2)+4s(1-s)(b1*e1+b2*e2)

V=V0+g(s)[Cp(s)-C0(s)+(exp(interp(logr))-1)*radial+local_residual]，g(s)=s²(3−2s)。三个log半径在s=0/0.5/1线性插值，缩放已有截面的径向距离，不强制截面变为圆形，也不直接生成新的管面。长度指数限[-1.5,2]，半径指数限[-1.5,1.5]。底盖、截断边界仍受原 FreeVertices 约束。实际曲线长度由有效混合曲线测量，不把系数当作物理位移。

优先尝试曲线参数梯度和局部残差梯度方向，再尝试联合 Adam/steepest。所有方向仍受同一完整目标及几何门禁；不放松 Ring 约束。该表达比重新建管状几何更保守：只能连续拉伸已有连通片，不能改变拓扑或生成新采样。若无法表达细长柄部，应报告这个实际差异，不能称已完成独立管状柄重建。

## 数值门禁和公平性

种子来自当前 FIT-only 状态。优化前检查 q=0 与共享起点相同、11参数各有物理响应、全梯度有限；保留各损失分量梯度与加法一致性原1e-4诊断，不调整失败阈值。三组均最多80次候选/40次接受/连续30次拒绝停机；8级回溯，Adam .02，密集32 CAD + FCL + 反向包含 + 自交。每步同一 tau，累计1D。使用最后接受状态，不按GT/留出选轮次。

历史239/30复核与当前种子、梯度分开。最终密集64审计独立于训练。真实柄部长度/半径若没有独立对应真值，明确 NOT_EVALUABLE 或条件代理；不以外观或 Dxy 接近声称长柄恢复。
