# MonoSDF Local Multi-Polyp Exploratory Training

本任务记录研究者最新两段指令的执行范围；完整原文保留在当前Codex对话。唯一执行智能体，不委派代理。

目标：本地GPU对至少三个独立物理息肉进行有限M1横向探索，观察连续SDF、HERO主面保留、多层/接缝、合理侧面、未知封闭和训练时长效应。不宣称最终科学验收。

输入继承最新KEY版本、E3-A/B/C/D、当前统一Camera Gate、View Partition、A2/V5/V6以及最近MonoSDF工程。冻结原生HERO/RGB/Mask/K/c2w/CAD和公制尺度。保留条件研究输入身份，不能放宽资格阈值。G01_004不与G01_005混合，GT/Oracle/DXY不读取或修改。

初始要求200–500步工程检查、稳定后1000–2000步；追加要求以实际当前M1优化次数N为基线，累计10N，保存1x/2x/5x/10x，优先保持相同骨干、损失、数据和优化状态。逐物理组独立模型，GPU仅串行，不干预其他用户作业。不因早期几何差停止，不以低Loss或好看Mesh认证。

实际审查发现正式M1尚未启动（N=0），只有两项25步一次性资源测试；不能将M0或资源测试重标为M1。研究者已明确答复：“M1 基线1000步，累计到10000步”。因此本任务各组正式新M1从0起，到1000建立基线，继续累计至2000/5000/10000，不重置优化器。既有M0完整11k状态/历史结果只读保留作为独立历史对照。

本轮冻结选择G01_004、G06_004、G08_005各三个分区参考。当前M1骨干/官方采样与渲染、网络损失和优化调度不变；必要适配仅来源调度/独立场景单位/恢复监测。原官方200k调度不压缩成10k。主阶段统一256³真实iso0 Mesh，不删面/平滑/补洞，无解析球或点云替代SDF输出。

交付：版本回执、资格/来源、配置、实际日志、完整检查点与恢复方法、真实场/Mesh、固定原生分母、四核心图（含同组1x/2x/5x/10x同相机同毫米比较）、失败记录、技术报告和GitHub独立分支。原始大资产/模型权重不上传，仅本地索引。

必须回答独立物理组数、每组实际更新/耗时、主面保持、多层/收缩、新侧面证据、跨组趋势和下一轮算力投入候选。最终区分真实几何代理改善与单纯拟合图像损害HERO。完成本轮停止，不自动扩大规模，等待研究者/PM验收。
