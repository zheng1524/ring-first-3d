# 同核双向局部恢复：运行前冻结

当前目录内继续，记录名SAME_KERNEL_BIDIRECTIONAL_001。父实验提交4cf944b及其源码/协议/结果全部保留，原FINAL不写入。仅两个对称处理，不执行Ip/Is、半径搜索或额外优化器。

## 对称设计

两组完全复用原64,239节点、137,184四面体、h=0.15mm BASE_FIELD；同一Wendland C4、R=1.8200001027435067mm及原样Kaolin DMTet。位置采用上一轮**预登记的控制位置**，不采用上一轮拟合中心；生成参数仅存各case的audit_only/GT_DESIGN.json。SDF内负外正：A幅值−0.39mm产生扩张，B幅值+0.39mm产生收缩。绝对SDF幅值相同，不预设物理位移相同或等于0.39mm。

初始主体必须是同一BASE_FIELD经DMTet提取的零面；GT也调用同一Body.mesh，不再使用原CAD Mesh作为GT或初始表面，不作法向顶点编辑。各状态真实V/F可能不同，Blender按各自V/F重建对象，不在不同拓扑间zip顶点。初始、GT和预测共用网格、坐标、尺度及提取流程；精确重提取GT比对V/F是生成合同，不是拟合。

## 原算法及相机不变

model.py、renderer.py、fit.py、projection_gate.py及官方vendor按原字节复制。common.py只改运行目录R/仓库REPO路由，数值函数与GT审计钩子不变。仍为中心XYZ+幅值四参数，Powell、原目标（双向轮廓Huber/9 + 0.2固定类分母XOR）、原初始化（Mask差异加权可见表面点）、相同边界/12轮/500函数评价/xtol0.01/ftol1e−5。不得把GT位置作为起点、不得在A/B间传递拟合参数。

拟合obs01/03/05、留出obs00/04，五相机及Ring CAD字节与父实验一致。A/B各自重新渲染BASE和TARGET并重跑投影门禁：主体/Ring IoU≥0.99，轮廓p95≤1原生px，点误差<0.001px。未通过不得拟合。原Blender/CV变换和像素中心−0.5约定保持。DMTet导数测试因源码/输入约定未变只读复用，不能将其写成新相机门禁。

两组GT设计、生成及协议先于任一组拟合冻结。优化器仍禁止audit_only/.blend/旧仿真目录读取。只允许初始场、目标Mask、相机、CAD，不把GT参数写入优化配置。最终按原规则取最后有界迭代，不按GT或留出结果选择较好检查点。

## 独立评价：统一算子与真实体积

预测冻结后才读取各组GT参数。共同评价域为同一初始DMTet零面的全部顶点，面积权重固定。GT及预测均用**相同**有符号最近面距离变化：d(X)=−sd(M_updated,X)+sd(M_initial,X)，正为向外、负为向内。GT实际区域固定|d_GT|>0.01mm；错误区域为其补集，同时报告GT支持球外结果。报告核中心误差/逐轴偏差尤其Z、位移加权质心、区域IoU、方向、峰值和误差完整分母；不混入材料点位移。

同法线射线作为独立核验：初始顶点X及法线n，X+0.8n向−n；GT、预测相同算子，未命中NaN，不填补。主表距离算子和射线读数分列，不挑有利口径。

每个记录轮次检查原始Mesh闭合/连通/绕序、邻面角p95/最大、FCL全三角面Ring距离/相交；初始/GT/最终另用Blender EXACT。收缩不能只凭Mask宣称成功：须检查预测SDF节点相对初始单调增加、Mesh真实体积减少、实际几何位移为负，并记录GT删除区与预测删除区的重叠。

用固定同四面体的4点对称积分估计三维新增/删除体积、交并比及错误区域体积；指示函数积分为离散代理，必须与封闭Mesh体积差并列，不能当连续精确体积。GT/预测都用与实际提取相同的float32节点值，格点和积分点不随输出改变。

沿用原冻结定位门槛：核中心/更新质心误差≤0.5mm、GT区域方向一致≥95%、物理峰值相对误差≤25%、非目标区域位移p95≤0.05mm、邻面角p95增长≤5°，闭合单连通和Ring无交；任何失败保留。

## GT参数目标值诊断（只在预测冻结后）

从原fit.py AST提取内层evaluate与huber，使用相同Body、Renderer及固定拟合视角，**单次**代入GT参数、最终参数、初始化参数；不启动第二次优化或参数扫描。记录轮廓与XOR分项及GT前向Mask IoU。GT损失比最终低超过max(0.002, 0.1×|L_GT|)定义为“明显优于”；门槛在运行前登记。

若GT几何重投影好、GT目标却不低，应报告损失/离散轮廓采样的偏差，不能擅自改目标。若GT目标明显更优，检查既有优化轨迹与初始化离GT距离、是否进入其邻域；不得以GT重启、改方向、加预算或挑最佳轮。局部极小与全局不可辨识需分开，轨迹证据不能证明唯一因果。

两个结果均报告后停止。只有二者同时正确定位才支持“上轮偏差可能主要来自表达不匹配”；否则继续保留对初始化、轮廓目标与局部搜索的质疑，不将单次试跑外推为不可能性定理。
