# 三、工作包 A：掠视角点云清理

## A1. 实验目的

验证研究者提出的假设：

**大面积稀疏、异常拉伸的点云，可能与局部表面接近掠视角有关。**

这是一项有限候选方法实验。

不要将其扩展为长期的角度清理算法研究。

## A2. 数学定义

对原始点：

\[
p_i\in\mathbb R^3
\]

获取该点真实来源参考相机的中心：

\[
c_i
\]

计算单位观察射线：

\[
v_i=
\frac{p_i-c_i}
{\|p_i-c_i\|}
\]

在原始局部表面上估计单位法向：

\[
\|n_i\|=1
\]

计算：

\[
\boxed{
\beta_i=
\arcsin\left(
\operatorname{clip}(|n_i^\top v_i|,0,1)
\right)
}
\]

结果转换为 degree。

其中：

- 小角度表示射线接近切平面；
- 大角度表示射线接近表面法向；
- 极小角度仅表示潜在不稳定观测，不等于真实错误标签。

必须检查坐标系一致性。

**射线必须来自该点的原始参考相机。**

不得使用可视化虚拟相机或其他参考相机代替。

## A3. 法向估计

优先复用现有：

- 原始有效三角面；
- 源像素邻接；
- 冻结的点云邻接；
- 既有法向计算工具。

在 Raw 原始几何上一次性计算法向。

只允许进行必要的法向可靠性检查。

对于：

- 不稳定法向；
- 深度突变；
- 遮挡边界；
- Ring 附近；
- Ip 细柄；
- 主体明显不连续区域；

必须记录可靠性。

法向不可靠的点不能仅凭角度被强制删除。

可以用一次局部 PCA 法向作为诊断对照，但不开展多种法向算法的性能竞赛。

## A4. 固定阈值实验

只运行：

```text

Angle-20
```

\[

\]

\[

\[
\beta<20^\circ
\]

只能增加一个组合，明确 AND/OR 逻辑，不开展新的阈值搜索。

# 五、工作包 C：锚点定位与有限刚体配准

本轮区分两种锚点职责。

## C1. 位姿锚点

- 息肉稳定特征；

- 必要的远端背景。

优先复用成熟方法：

- SIFT / LightGlue / RoMa；
- RANSAC；
- PnP；
- Point-to-plane ICP / GICP；

必须考虑 Ring 旋转对称性。

背景匹配可以用于补充位姿约束，但不能因远端背景点数量多就使其主导优化。

使用适当的区域均衡采样。

记录不同区域匹配的数量、空间分布及几何残差。

**Polyp 真实观测 > Polyp 邻近几何 > 远端背景。**

不要把背景配准成功直接等同于息肉表面正确。

## D2. 分类

对目标参考视角中的区域区分：

```text
EXPLAINED
NOVEL_CANDIDATE
OCCLUDED
GEOMETRIC_CONFLICT
UNKNOWN
```

### EXPLAINED

主面已经能够合理解释的真实观测区域。

其他参考中的对应点用于辅助验证和定位，但原则上不重复加入最终场景。

### NOVEL_CANDIDATE

目标参考确实观察到，而主面没有合理解释的区域。

此类区域应优先进入新增表面分析。

不能仅因其距离主面超过历史 0.3 mm 阈值，就直接拒绝。

### OCCLUDED

因 Ring 或可信前景遮挡而无法观察的区域。

不应误认为新增表面。

### GEOMETRIC_CONFLICT

主面和次参考对同一可见区域存在明显不一致。

保留冲突证据，不能强行平均。

### UNKNOWN

现有证据不足以判断。

保留来源和状态。

不能假装已知其真实几何。

## D3. 反向映射

将新增候选区域关联回次参考原始点云。

- 原始点 ID；
- 源像素 UV；

- 原始 RGB；
- 法向；
- 来源观察角度；
- 目标视角支持；
- 遮挡状态；
- 冲突状态。

这里需要重点解决的问题是：

**过去融合算法没有接受的新表面，究竟是因为真正重复、位姿不准、深度冲突，还是融合规则过度保守？**

请把这几种原因分别统计，而不是统一记为融合失败。
