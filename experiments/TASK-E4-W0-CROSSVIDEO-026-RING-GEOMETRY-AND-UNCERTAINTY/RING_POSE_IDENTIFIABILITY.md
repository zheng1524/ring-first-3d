# RING_POSE_IDENTIFIABILITY

固定真实 Ring 观测，仅改候选相机（005 FIT 视角）：E_Ring 随扰动的变化

| 扰动 | E_Ring |
|---|---:|
| 0° yaw | 0.260 |
| **1° yaw** | **0.560** |
| 5° yaw | 3.711 |
| 15° yaw | 9.231 |
| 45° yaw | 54.205 |
| 平移 0.1 / 0.25 / 0.5 mm | 见 `RING_POSE_SENSITIVITY.csv` |

结论：

1. **yaw 在 <1° 范围内几乎不可辨识**（0.26→0.56），符合 Ring 的旋转对称性；
   45° 时误差才显著（54.2），说明**完整 Ring 不能确定绕法向的绝对 yaw**。
2. Inner/Outer 对**倾斜/平移**敏感（5° → 3.7；0.25 mm 量级见 CSV），
   比 013 的简化 R0 更严格，但**对 0.5° 级相对相机误差仍不敏感**。
3. 该盲区正是 §P2 中"Ring 合格但 3D 变化明显"的根源。

多假设注意：Ring-compatible 搜索只能约束倾斜/平移，yaw 必须由真实背景 3D 提供。
