## 0. 现有事实与必须纠正的误解

022 已审计：G03 的 `MATCHES.npz` 内有 **96 组图像对、3749 条 SIFT 对应**，021 最终 H 下总体 Sampson 中位 **4.59344 px**、p95 **156.10182 px**、`>50px` 占 **16.61776%**。五条最高残差是**五个匹配点**，而不是“五组图像对的平均残差”。其中 video005 的 `raw00114` 出现四次，可能提示局部异常，但未按该帧匹配总量归一前**不能断言该帧有问题**。

当前 `cross_video_matches.py` 只有 SIFT + ratio 0.75 + 背景 Mask；**没有 mutual、RGB-RANSAC、多视角地标或三维同名身份**。正式目标仅 Ring(native)+EPI+Prior。G03 的 K 恰好与021硬编码值相同，所以硬编码 K 是工程缺陷但不能据此认定其为 G03 误差长尾根因。

Sampson 误差是配对点对违反预测极线的近似双侧几何距离，不是原始图像中两点直接相距几像素。**二维极线误差接近 0 不代表这对点是真实三维同名点**。

## 2. 执行顺序

### S0 — 读取和校验输入

核查 `MATCHES.npz` 的 `a,b,off,pa,pb`、`RESULTS.json` 的最终 H、004/005 各自 `camera_result.npz` 的 `c2w,K,ids`、PREPARED 的 `view/cache/raw_frame`。记录 SHA256。核查 021 里计算 `sampson_px` 的代码与报告公式，所有数据只读。

### S1 — 对每一条真实 SIFT 匹配逐点重算误差

以 **021 正式 `shared_se3.sampson_px`** 作为对照，并独立重建 F 用于作图。逐点输出：004/005 view ID、两端 (u,v)、官方 Sampson、两端各自点到极线距离、FIT/HOLDOUT、误差分层。必须数值核对：96 对、3749 点、中位 4.59344、p95 156.10182、>50 占比 0.16618；无法复现立即停止并报告输入/版本差异。

**误差分层仅供显示**：`<3px`、`3–10px`、`10–50px`、`>50px`；这些分层不是新准入门限。

### S2 — 绘制 4 类真实图（必须实际运行生成，不得只提供模板）

1. **96 对图像残差热图**：横轴 005 视角，纵轴 004 视角；左图每对中位 Sampson，右图该对 `>50 px` 比例。以各对匹配数加以说明。回答：高误差是集中在某些帧、某些视角组合，还是随机零散？
2. **所有真实匹配的残差分布图**：保留长尾，包括中位/p95/超 50 px 比例，不得只截断到 10 px。
3. **真实 RGB 的匹配连线图**：至少 `004 raw00242 ↔ 005 raw00114`、`004 raw00263 ↔ 005 raw00114`、`004 raw00304 ↔ 005 raw00114`、`004 raw00242 ↔ 005 raw00099`，另选两对误差较小的对照。连线颜色表示误差分层，图注明确**线的长度不是误差**。
4. **极线/点位叠加图**：每个误差等级至少 1 个真实点，左 004、右 005；在两张 RGB 上画预测极线（蓝绿色）、真实匹配点（彩色）、到极线的垂足与连线（红虚线），分别标 Sampson 与单侧点线距离，裁剪并适当放大需要查看的局部。不允许只画没有图像底图的抽象直线。

额外推荐：将同一 005 帧所收到的所有 004 观测按 `>50` 颜色覆盖在**真实 005 RGB**上，检验离群点是否聚集于 Ring/Polyp 边界、反光、重复纹理或背景空白。

### S3 — 找到误差原因，不仅仅是“超过多少像素”

沿相同的原始匹配身份进行下列**互相独立的只读对照**：

**A. 匹配本身是否真实**：原图局部裁剪查看两端斑点是否同一物理纹理。统计反向 mutual 一致性、特征重复/边缘/反光、Mask 标签；用 OpenCV `findFundamentalMat` USAC_MAGSAC（明确工具/阈值）估计仅由 RGB 对应得到的 `F_img`，只作对照，不改变正式优化。报告匹配数量在每个诊断阶段的变化。

**B. 当前相机几何是否错误**：用冻结 W0 + H 计算 `F_pose`，比较同一批原始匹配在 `F_pose` 与 `F_img` 下的误差分布，并输出两种极线在同一 RGB 图上的叠加。若图像匹配多数支持 `F_img`、却不支持 `F_pose`，优先审查相机/共享 H、坐标方向和时间帧对应关系；不能直接宣称 SIFT 错误。

**C. 是否存在退化/遮挡**：检查每对相机中心间基线、相对旋转、可视区域重叠、预测极点、匹配在图像中的空间分布；确认是否极低视差、近平面/重复纹理、被 Ring/息肉遮挡或 Mask 边界误归类。必要时展示局部原图。

**D. 是否为单帧问题**：对 raw00114 以及前述异常帧统计**每帧的匹配总数、>50px 比例、图像对数**，与邻近 raw00099/raw00128 等参照帧比较。单凭 Top5 不能认定 raw00114 是坏帧。

**E. 对照 W0 质量**：只读取 W0 ACCEPT 视角的 Ring/Held 指标；针对发生异常的 004/005 相机做相机内部 Held 与跨视频残差对照，区分“单段相机已经有问题”与“跨段匹配/共享 H 有问题”。

**注意**：同一错误匹配即使 Sampson <3px 也可能是“碰巧落在极线上”，不要仅靠极线误差进行真假标签。可优先利用 019/020 历史多视角轨迹、双向交叉检查作为额外证据，但本任务不恢复/修改正式算法。

### S4 — 基于证据划分根因及下一轮行动

最终报告至少按 **MATCHING_ERROR / CAMERA_GEOMETRY / LOW_PARALLAX_OR_DEGENERACY / MASK_OR_OCCLUSION / IMPLEMENTATION_OR_PROVENANCE / UNRESOLVED** 分类，每一类必须给真实图、样本数量、典型点对坐标、误差及支持/反驳证据，**不允许因单张图主观猜测就给“确定”结论**。

最后提出 023 对应最小修复建议，但未经人工明确批准不得实现或训练。若现有数据不能区分，明确列出最少需要新增的观察或可视化。
