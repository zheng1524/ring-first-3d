# R1 全量粗主体初始化与基底截断

本轮完成 **118 个新初始化：79 单视频、39 联合**，覆盖 39 组、79 视频；失败槽 0。其中 21 个为明确标记的二维约束结果。它们是可审阅粗初体，不是已验证真实形状，也没有启动自由顶点更新。

## 结论与限制

- **已经验证**：R1 输入身份、79 视频审计、原 62 个 M4 变换逐值不变；新增 17 视频可读取相机/二维观测并获得冻结 M4 的数值变换。1153 HERO 来源从 state==0 的真实原面筛出原生像素，不将完整 V 当可信点云。新变换没有获得绝对配准精度认证。
- **已经执行**：同一个九参数椭球框架；单视频仅用自身观测，联合真实重算全部参与观测。配置 {'DXY_MASK_HERO': 97, 'DXY_MASK_2D_ONLY': 21}；基底状态 {'RELIABLE': 29, 'WEAK': 68, 'UNOBSERVABLE': 21}，启用可靠基底并细化 29 个，其中 28 个真正产生裁切交点/底盖。弱基底候选与正式未裁母体分开，未借基底门控跳过二维初始化。
- **初步有效**：共同二维观测能给出多数可解释的低维轮廓；联合相对单视频平均留出 IoU 改善 9/39 组，差值中位数 -0.0042。这个共同样本比较保留全部组，并不说明联合总是更好。
- **仍需研究**：深度偏置可辨识性、局部背景是否真为附着面、头部与未解释蒂部的关系。不能把 RELIABLE 的内部一致性标签当独立基底真值。
- **当前无法评价**：真实部署形状精度、绝对基底位置、真实 HERO 偏差。没有为真实数据读取 GT 或按 GT 调参。

每配置初值仅来自 DXY/Mask 像素中心射线和投影尺寸。弱视差时显式使用 Ring 邻域深度先验；不是三维实测。固定 8 个二维拟合视角、2 个主体二维留出视角/视频，每 HERO 最多 64 个可信原生像素。表中 IoU 在运行前固定的 16 px 网格计算，是采样轮廓指标；不是全分辨率像素 IoU。按视频、方向密度及 Target/Support 重叠分配固定来源质量，未按贴合程度调权。真实可见轮廓权重高于 DXY 补全先验；背景 RGB 地标未用作息肉深度真值。

实际 DXY 像素候选为 758/790 个唯一选定帧；缺候选帧仅使用原 Mask 观测，未换用新 DXY 版本或隐藏补全形状。逐组 HTML 与结果表列明可用数。

theta 使用有界最小二乘，b 使用逐来源一维求解与完整目标接受检查。`|b|≤0.4 mm`，先验 sigma 0.15 mm，深度尺度 0.5 mm。先拟合母体，再固定可靠平面做短细化；目标只在同阶段比较。412 个阶段步骤通过非增检查。母体切换到裁切模型后目标可能上升，此跳变单独保存。DXY仍作为完整母体先验；真实可见边界与Mask项包含截断轮廓。实际 |b| 中位数 0.0121 mm、最大 0.1366 mm（单/联合来源配置合计，不是独立样本统计）。

可靠平面方向依据观测相机位于局部背景的哪侧，并另检突出/接触证据；不按近零息肉高度中位数定向。背景/CAD不应用 b，平面不是世界高度减 b。保持平面固定；底盖只用于封口，cap-only 原生观测仍计未解释并受罚。固定深度分母在全部配置合计 147584（同一来源在单/联合中分别计），失效 2709；唯一 HERO 来源数为 1153；来源共享 Target/Support、存在相关性，组级比较分母为 39 组。

优化前向使用同参数的解析截断椭球；交付表面用 subdivision=3 的 icosphere 离散并作原010精确三角裁切。不是将完整体拟合后盲裁。另用实际交付三角Mesh、完整原图网格复核投影和原生轴深度，记录在 `VISIBILITY.json` 与结果表的 `full_mesh_held_IoU` 等列；全分辨率 Mesh 指标上，联合优于单视频平均的组数为 10/39。解析/离散深度差的最大来源P95为 0.1185 mm，不能把两种表示称为逐像素完全相同。62 个配置有模型顶点落在CAD实体内部，最大顶点穿入 0.587 mm；这是待处理的粗体矛盾，不等于完整三角碰撞检测，也没有因原HERO可信就忽略它。

## 受控检查、反例与实际观察

复用已有虚拟 G01 三角网格与渲染器，重新生成观测；本轮已知支撑平面放在该既有形状最低附着点，是声明的控制条件，不冒充历史实测背景。GT 和注入量只在生成/冻结后评价中使用。固定真实网格诊断的 b 恢复误差均小于 0.001 mm；正确 b 沿射线反投误差也小于 0.001 mm。

**粗椭球并未准确恢复注入 ±0.25 mm**：约校正 ±0.02 mm，保守先验与低维形状误差仍占主导。该失败保留，未据 GT 放宽偏置。完整母体对虚拟 GT 单向距离中位/P95 为 0.080/0.391 mm，仅为受控指标，不是全面覆盖精度。

错误基底高度切侧观测 214/512，翻侧 509/512；翻侧触发整主体裁除失败，没有用完整母体冒充裁切成功。真实宽接触示例中 005 产生实际截断；其 004 和联合平面不够稳定，保留候选。Ip12/R10 的 004 无 HERO，仍给出二维初体；蒂部不由椭球强拉成粗底座。

最低留出轮廓结果：`GP_IIa_22.0mm_closed_R10_single_refY / JOINT`，IoU 0.532。所有缺失、CAD 冲突、切侧原始可信点和失败槽均在 CSV/JSON 内保留。几何更一致或优化收敛均不等同于科学重建成功。“留出”仅指没有进入显式二维拟合项；这些帧仍可能作为 HERO Target、Support、Clean 和上游相机输入，因此不是独立数据留出，也不能称端到端独立测试。

冻结后诊断没有替换预测：9/39 个联合配置在某个可行单视频参数位置得到更低的同一联合完整目标（固定联合 b），说明确定性起点/局部停滞仍有限制，不能宣称求得最优。IIa22/R10 联合 IoU 约0.53，两个单视频约0.97/0.90；单视频参数直接探测并未降低其联合目标。该组005的10个抽样帧上游Q1通过数为0、已有RGB留出MAE中位约11.22 px；更支持共同坐标/内部观测约束冲突的解释，但尚未排除其他局部最小。这个视频仍有二维初体，没有按 HERO 零产出直接拒绝。完整诊断在 `POST_FREEZE_DIAGNOSTICS.json`。
