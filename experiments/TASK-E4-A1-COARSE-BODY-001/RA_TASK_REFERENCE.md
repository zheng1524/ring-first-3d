## 1. 被研究的数学问题

### 1.1 已知量、未知量及证据性质

对一个合格的**单视频、同一 Ring 坐标系**，已知：

- `K_i,T_i`：第 `i` 个视角相机内参、Ring-First 公制位姿；使用已冻结 Camera Gate 资格。
- `M_i`：原始 Polyp/Ring/Background Mask；`C_i`：既有 DXY 主体圆／椭圆及 P/Q 边界信息；**C_i 是二维主体位置、尺度、投影形状的软线索，不是真实三维截面，也不必等于真实外轮廓**。
- `D_i^H`：既有 HERO 深度、有效性域及源参考；`P_i^H`：由已冻结 P0 反投影的局部公制表面／点。
- `B_i`：真实 Background 的候选三维点；`R_CAD`：固定公制 Ring CAD 实体，仅用于已有相机／遮挡检查。

未知量为息肉类别 `c∈{Ip,Is,IIa}` 的低维主体参数 `θ`、主体表面 `S_c(θ)`、可选局部附着几何参数及其不确定性。**不把待求量扩张为自由相机位姿、自由 HERO 深度偏差和自由全局 SDF**；否则历史已发现的相机轴向位移－HERO 深度偏差耦合会使结果难以辨识。

### 1.2 主体几何与投影

定义各类别的候选几何族：

\[
\mathcal S_c(\theta)=\{X\in\mathbb R^3:F_c(X;\theta)=0\},\qquad
\widehat M_i(\theta)=\operatorname{Silhouette}(\Pi_{K_i,T_i}(\mathcal S_c(\theta))).
\]

其中 `F_c` 为参数化曲面函数；`X` 为毫米坐标的三维点；`Π` 为已知相机投影；`\widehat M_i` 是该主体在视角 `i` 中的预测轮廓。对 Ip，先只拟合“头部”主体，避免细柄稀疏观测扭曲头部优化。

**几何族不得一开始写死为椭球**。保留椭球作为最小参数对照，并比较形态条件化、但仍低维的形状族：

| 类型 | 最小对照 | 应比较的形态候选 | 本轮可作出的声明 |
| --- | --- | --- | --- |
| Ip | 可旋转椭球头部 | 低阶球谐／有界径向头部（须近似星凸） | 头部形态和位置；柄只作为 A2 中的潜在连接假说 |
| Is | 可旋转椭球 | 带可变接触边界的球冠／截断超二次曲面 | 隆起主体及可能的基底接触带；真实底面未直接观测时不能声称被测得 |
| IIa | 薄椭球 | 低维非负高度场、广义椭圆平缓隆起 | 宽基底、低高度形态；避免薄椭球的虚假背面 |

对低阶星凸头部可采用

\[
r(\omega)=\exp\left(\sum_{\ell=0}^{L}\sum_{m=-\ell}^{\ell}a_{\ell m}Y_{\ell m}(\omega)\right),\quad L\in\{2,3\}.
\]

其中 `ω` 是头部中心出发的方向，`Y_{ℓm}` 为球谐基，`a_{ℓm}` 为少量形状系数；指数保证半径为正。这是**候选数学参数化**，不能当成已经证明适用于所有 Ip 的结论。

对 IIa 可采用局部坐标下

\[
z=h(u,v;\theta)\ge0,
\]

其中 `u,v` 沿初步接触切平面，`h` 是少参数、平滑且有限支撑的隆起高度；**真实 Background 平面资格及接触约束由 A2 再引入**。

### 1.3 同时使用二维主体线索和相对深度

统一的 A1 目标写为

\[
\boxed{\hat\theta
=\arg\min_\theta\left[
\lambda_C E_C(\theta)+
\lambda_D E_{\Delta D}(\theta)+
\lambda_H E_H(\theta)+
\lambda_R E_R(\theta)
\right].}
\]

各项分别为：

1. `E_C`：预测的**头部投影轮廓／中心／宽高比例**与现有圆／椭圆及可靠 P 边界之间的鲁棒差异；Q 区域作低权重或不确定区间，不把 DXY 测量圆当成精确真值。
2. `E_{ΔD}`：同一视角、多个合格头部像素之间的**相对深度差**：

   \[
   E_{\Delta D}=\sum_{i,(u,v)\in\mathcal Q_i}w_{iuv}\rho\!\left(
   [\hat d_i(u;\theta)-\hat d_i(v;\theta)]-[D_i^H(u)-D_i^H(v)]
   \right).
   \]

   `\hat d_i` 为主体的预测首相交深度；`\mathcal Q_i` 是同一张图中可靠像素对；`w` 是来源质量权重；`ρ` 为鲁棒损失。差分避免把每视角统一轴向偏差当成可独立恢复的真实物体高度，但**不能**解决全部相机／深度可辨识性问题。
3. `E_H`：已清理且通过资格检查的 HERO 头部局部三维点到粗主体的**软支持约束**，按源面面积、视角和独立物理组归一化，不因重复采样点多而占优。它只影响粗轮廓，不要求精确逐点贴合。
4. `E_R`：形状简单性、参数范围、无病态尖峰／锥体、尺度和曲率正则化；防止复杂形状在少数视角上过拟合。

**统计注意**：Mask、DXY 拟合、HERO 均来自相关的 RGB，不能把三者相加称为三份独立测量证据；必须通过消融与留出视角测试它们的边际作用。

### 1.4 可辨识性分析是 A1 必做内容

对参数 `θ` 构造白化后的观测残差雅可比 `J=∂r/∂θ`，报告奇异值、条件数及不稳定方向；做受控小扰动和重复初值，检验不同形状是否能同样解释现有观测。

**只要不同形态给出近似同样的 2D／相对深度证据，就应报告形态不唯一或参数区间，而不是选一个外观漂亮的结果冒充已恢复真值。**

## 2. A1：三类息肉主体粗拟合实验（本轮授权）

### 2.1 研究假设

**H1**：相较仅使用二维主体椭圆或仅使用 HERO 的三维椭球，结合“可靠投影头部线索＋相对深度”的低维模型能更稳定地解释**未参与拟合的真实视角**。

**H2**：Ip、Is、IIa 存在有意义的形态差异；类别条件化几何比统一椭球更合适，尤其是在 Is 的基底截断和 IIa 的扁平隆起上。

### 2.4 四个固定实验动作

1. **几何反例检查**：在可控合成椭球、截断球冠、宽基底隆起、头柄分离体上，展示不同三维物体可给出相似二维圆／椭圆，且单视角相对深度不能唯一决定隐藏面。合成 GT **仅用于本合成检查**。
2. **同输入预算对照**：固定 2D 目标区、合格参考视角与其来源权重，运行 A1-0…A1-3，报告收敛、失败、病态形态及敏感度。
3. **逐视角留出**：从 A 集合拟合 3D 主体，到未用于拟合的 B 真实图像验证预测 Polyp／头部轮廓、首层深度相对起伏和不合理外扩；不得用 B RGB 上色后再宣称 RGB 重投影良好。
4. **稳定性诊断**：小范围调整头部轮廓、参考视角、初始化及相对深度权重，记录 `θ`、预测形态和留出误差变化；估计是否存在不可辨识方向。

### 2.5 A1 评价与 Gate A1

固定输出：

- **几何解释**：留出 Mask/head 支持区域的 IoU、轮廓边界距离（px）、外越界比例；预测首表面的相对深度残差（mm，合法时），均在**事先固定的像素和源射线分母**上报告。
- **粗形态**：头部公制宽高与尺度范围、长宽高比／IIa 峰高与接触域候选、连续连通性、异常尖峰／锥体、自交及高曲率异常；这些是形态诊断，不是独立 3D GT。
- **可辨识性**：雅可比奇异值与条件数、初值及小扰动敏感性、模型复杂度—证据解释权衡。
- **诚实的失败**：每组的合格／受限／不合格状态，全部候选、未拟合成功、不可评价数量；不得只展示最好的一张。

Gate A1 通过的必要条件：**至少有一组具有冻结、独立留出证据的合格实例证明多视角模型不退化**；各类型的结论分别成立或明确 `NOT_EVALUABLE`；新增复杂度必须展示相对基线的留出收益或相同证据下更稳定的几何。任何“锥体”、无约束长尾或明显违背多视角轮廓的模型均不能以训练损失低为由验收。若合格 Is 缺失，**不得宣布“三类型实证验证完成”**。

## 3. A2：背景平面与附着拓扑约束（本轮授权）

### 3.1 背景必须来自真实邻近组织

在历史合格相机下，从真实 Mask 外、与息肉相邻的 Background XYZ 估计

\[
\Pi_b=\{X:n^\top(X-p_b)=0\},\qquad h(X)=n^\top(X-p_b).
\]

其中 `n` 是指向息肉一侧的单位法向，`p_b` 是局部平面一点，`h(X)` 为相对背景的有符号公制高度。**不得拿 Ring 平面代替背景平面**；必须复用历史背景 ROI、RANSAC、样本资格及不确定性审计。无法稳定估计时标记 `BASE_UNCERTAIN`，而非推测一个确定底面。

### 3.2 三类约束应当不同

| 形态 | A2 解释 | 应避免的误判 |
| --- | --- | --- |
| **Ip** | 若头部与可信背景面之间有显著正间隔，推断**可能存在连接柄**；仅输出潜在连接走廊／尺寸区间，等待实际 Mask/HERO 支持 | 不可把头部强制拉到平面，也不可凭间隔直接生成“真实柄” |
| **Is** | 主体隆起和接触面相交，可用背景面截取头部形态，求**模型推定**的接触边界／基底 | 几何截面不是直接观测的解剖底面；不可无证据地宣布完整体积 |
| **IIa** | 附着区定义低幅、高度非负的连续隆起；用平面约束高度场的零边界／过渡平滑 | 不可将薄隆起恢复为完整椭球后再补一个虚假背面 |

对 Ip 的椭球头部，若

\[
\mathcal S_h=\{X:(X-c)^\top A(X-c)=1\},\quad A\succ0,
\]

则头部到基底参考平面的最小法向间隙为

\[
g=n^\top(c-p_b)-\sqrt{n^\top A^{-1}n}.
\]

`c` 为椭球中心，`A` 为形状矩阵；`g` 为**主体模型与平面间隙**，不是实际柄长。只有当 `g` 在背景平面、相机和主体参数的不确定区间内仍显著大于 0，且观察不与该假设冲突时，才给出“可能有柄”的标签。

### 3.3 固定对照与 Gate A2

每个具备可靠背景条件的同一案例，比较：

- `A2-0`：A1 最优主体，**不施加**真实背景附着约束；
- `A2-1`：相同主体与相同输入，仅加入**合格**背景平面、非穿透及类别附着先验；
- `A2-2`：若平面不合格，保留 `BASE_UNCERTAIN`，只展示未约束主体与原因，**不拿假平面补数**。

评价包括：未留出视角的轮廓／深度是否退化、主体与真实背景穿插比例、Ip 间隙区间、Is 模型接触区域、IIa 高度非负与平缓过渡、对 ROI／平面扰动的敏感性。历史 H95 是源观测点高度的 95 百分位，**不是头部－背景间隙，也不是已知真实峰高**。

Gate A2 通过的必要条件：与 A2-0 相比，在合格背景组**减少不合理穿透／附着并保留留出几何解释能力**；所有基底推断附有可用性与不确定区间，未观察的柄、底面及体积须标为“假设／模型推断”。

## 4. B1/B2 未来接口（**不是本轮执行任务**）

### B1：主体作为脚手架，可信 HERO 作原始几何证据

A1/A2 输出**粗主体 `S_0` 和每点可信域标签**，并保留原 HERO `Raw/Cleaned`、参考 ID、三角面 ID、观测相机、投影／遮挡关系。B1 在人工另行批准后比较：

2. **B1-G：有界几何形变／局部残差**。只在经验证支持域内使粗主体贴近局部 HERO，保护高信任区域，并对位移和曲率施加上界；不能通过大规模丢弃源射线降低误差。

B1 的一级验收不是闭合率，而是：**可信原几何保留、固定源射线覆盖不下降、真实 B 视角解释不恶化、未观测区域与接缝来源清楚**。几何光滑和闭合属于次级目标。

### B2：残差隐式表面是可选分支

只有 B1 在真实案例上证明粗主体有效、有明确保真瓶颈后，才讨论

\[
F(X)=F_0(X;\hat\theta)+\Delta_\phi(X),\qquad \|\Delta_\phi\|\ \text{受局部支持域与可信度约束}.
\]

即对已拟合几何学习**有界残差**，不是从原始 RGB 重新自由训练一个全局 MonoSDF。需防止重复交点、空洞外扩和巨型锥体。B2 是否存在不构成 A1/A2 的通过前提。

### 来源标签接口

至少区分 `OBSERVED_SUPPORTED`、`SINGLE_VIEW_SUPPORTED`、`PRIOR_INFERRED`、`BASE_INFERRED`、`CONFLICT_UNRESOLVED`、`CAD_OCCLUDED`、`UNKNOWN`。**任何可视化中推断表面不得伪装成真实 HERO XYZ**；CAD Ring 始终是独立已知实体。
