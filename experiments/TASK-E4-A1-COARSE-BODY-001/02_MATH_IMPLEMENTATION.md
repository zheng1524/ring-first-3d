# A1 数学与实现

公制 Ring 世界坐标 mm；c2w 把相机轴向坐标变至世界。射线 X(t)=C+t R K⁻¹(u,v,1)，不归一方向，因此 t 是相机 Z（mm）。CAD 与主体均采用同样约定。原生352×640与归档360×640映射复用冻结代码；不把两者像素坐标直接混用。

椭球：X=c+Q diag(a)n，‖n‖=1，9参数（中心3、旋转向量3、log轴3）。闭合背面明确属于先验推断。

Ip 星凸：X=c+Q diag(a)[r(n)n]，r=exp[0.2 tanh(B₃(n)β)]，7个三阶实多项式基，合计16参数。基不是正交归一球谐；名称“有界三阶星凸”准确。正半径连续单值，不能产生任意自交/长尾；不生成柄。

Is 球冠：椭球参数加局部归一z≥q，q∈[-0.65,0.4]。保留开放边，无底面。截断是形状参数，不是已知真实背景。

IIa：局部 x,y 椭圆有限域，h=H max(0,1-(x/a)²-(y/b)²)² exp(sx·x/a+sy·y/b)。H>0、|s|≤0.25；边界h及一阶导数为0，非负、有限支撑。11参数，只有上表面，不生成下表面。局部z=0只为模型坐标，峰高不是对真实组织基底的测量。

## 损失

EC 是24方向的可见投影凸支撑残差（已包含中心和投影尺度）；CAD遮挡顶点不参与该可见支撑。不能表达凹轮廓，也不能把Ring边自动当息肉外边。附加源D像素对投影支撑域的连续越界距离，减轻整条射线丢失时D无梯度的问题。

EΔD 用固定像素对的真实首次交点差减原生 HERO 轴向深度差。椭球/球冠根解析求解；星凸与高度场在合法有限射线域33点寻找最早符号变化，再28步二分。未捕获切触根可能造成离散偏差；S1 和真实解导出的高分辨率三角Mesh交点交叉检查，局部导数不稳定则明确标注。无相交不虚构深度，也不把命中个数当可微损失。固定射线/像素分母保持不变。

EH 是原始面上面积积分采样点到参数曲面**方向对应点**的3D残差。椭球/星凸沿局部归一径向，球冠受截断边界限制，高度场沿局部竖向。它不是精确最短距离SDF，不能宣称实现了最近点SDF拟合。每顶点面积权重由原始相邻三角形面积/3分配；每源96点，固定面积CDF抽样。冻结清理/Mask/CAD无资格的点不能增加权重。

ER 为固定初值中心/旋转/log轴及新增形状复杂度弱先验。实际总残差以各模态σ白化，robust soft_l1后乘面积/视角/样本质量因子。实现 g(x)=x sqrt[2/(sqrt(1+x²)+1)]，使g²=2(sqrt(1+x²)-1)，避免小x相消。优化器使用线性平方损失，不能重复鲁棒化。

## 数值验证与限制

metrics/S1_NUMERICAL_TESTS.csv：四类曲面真正首次交点与导出三角Mesh比较，坐标Z/射线距离合同、开放/闭合拓扑；单视图隐藏面反例；多视角相对深度局部秩与恢复；合成头柄分离。测试在真实优化前完成，合成真值不修改真实阈值。实现不调用网络、不拟合全局SDF、不将推断模型替换原始HERO。

S4白化J排除ER，物理尺度归一见01_PM_PROTOCOL.md。非光滑的轮廓最大支撑点、CAD边缘和丢失根会影响中心差分；报告两步长一致性、有限差分临近覆盖变化、秩和弱方向，不用先验填充观测秩。
