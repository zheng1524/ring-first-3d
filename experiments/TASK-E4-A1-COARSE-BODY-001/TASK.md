# 第三阶段：A1 三类息肉低维主体拟合

## 3.1 核心数学任务

对每个类别 c，建立低维参数曲面：

`S_c(θ)`

利用固定公制相机将其投影到各个视角。

我们希望优化 θ，使预测主体同时满足：

1. 合理的二维头部投影形态；
2. HERO 提供的相对深度关系；
3. 有资格的 HERO 局部三维软支持；
4. 低维形状与尺度正则化。

统一目标：

`E(θ) = λC·EC + λD·EΔD + λH·EH + λR·ER`

其中：

- EC：头部二维主体轮廓、中心、宽高比例等软约束；
- EΔD：同一视角内部可靠像素对之间的相对深度差；
- EH：真实 HERO 头部点到低维主体的软支持；
- ER：尺度、曲率、形状复杂度及异常尖峰正则。

必须使用正确的相机首相交深度，区分相机 Z 深度与射线距离，统一单位为 mm。

DXY 的 P/Q 点可以作为二维线索，但不是三维 GT。

Ip 必须区分“头部”与完整息肉 Mask，不能让细柄污染头部拟合。

## 3.2 三类几何模型

### Ip

比较：

- 可旋转椭球头部；
- 低阶球谐或有界星凸头部。

球谐优先选择低阶模型，避免参数过多。

本轮不生成真实连接柄。

### Is

比较：

- 可旋转椭球；
- 球冠或可截断的低维超二次曲面。

允许模型具有候选接触边界，但 A1 阶段不得把未经资格确认的背景平面当成真实基底。

### IIa

比较：

- 薄椭球基线；
- 非负、有限支撑、低维平缓高度场。

高度场的初始局部参考面只是模型坐标，不等于已测得的真实 Background。

特别避免 IIa 出现虚假完整椭球背面。

验证：

2. 单视角相对深度是否可能对应不同隐藏面；
3. 多视角条件下哪些参数可以稳定恢复；
4. 当视角分布不足时出现哪些不可辨识方向。

合成 GT 仅用于本实验的数学验证，不允许参与真实数据调参。

## 实验 E4-A1-S2：真实四组消融

在所有符合资格的物理组执行 A1-0～A1-3。

同一类没有合格真实数据时，明确记为不可评价。

报告成功、失败和不稳定结果，不得只保留最好的一组。

## 实验 E4-A1-S3：真实 A→B 视角检验

这是本轮最重要的实验。

从 A 集合拟合低维主体。

将拟合出的三维主体投影到真实 B 视角。

制作固定 B 视角的对照：

1. B 原始 RGB；
2. B 的 Polyp/头部线索 Mask；
3. A1-0 预测投影；
4. A1-1 预测投影；
5. A1-2 预测投影；
6. A1-3 预测投影。

优先复用历史 A→B 投影、CAD 遮挡和六视角可视化代码。

对照必须使用同一个 B 视角、同一内参、同一裁剪映射。

不能利用 B RGB 给三维主体重新上色后，再声称投影已经准确。

评价：

- 头部/主体轮廓 IoU；
- 轮廓边界距离；
- 固定分母的命中、未命中、越界比例；
- CAD 遮挡比例；
- 有效时的相对深度残差；
- 明显不合理的外扩区域。

所有指标以预先固定的像素和源射线为分母。

不能通过删除预测失败的像素使指标变好。

## 实验 E4-A1-S4：可辨识性与稳定性

对观测残差向量构造白化雅可比：

`J = ∂r / ∂θ`

分析：

- 奇异值谱；
- 有效秩；
- 条件数；
- 不稳定参数方向；
- 多初值结果；
- 轮廓轻微扰动；
- 相对深度权重轻微扰动；
- 参考视角变化；
- 冻结相机位姿的小幅受控扰动。

请注意：

雅可比必须针对残差向量，而不仅是总损失的梯度。

在计算条件数前，必须进行观测白化和参数尺度归一化。

相机扰动只做敏感性检查，不允许重新联合优化相机和 HERO。

如果明显不同的三维形态都能解释现有观测，明确报告：

`LOCALLY_UNIDENTIFIABLE`

或其他清楚定义的不确定状态。

不允许选择外观最好的一种并宣称恢复了唯一真实形状。
