# JOINT_LOSS_DESIGN

**前置：** 本文件先于任何相机训练冻结。所有实验臂共用同一配置 `configs/unified_config.json`。

## 1. 观测来源与物理意义

| 项 | 来源 | 物理意义 | 是否训练侧 |
|---|---|---|---|
| DXY inner/outer 椭圆 + 可见弧 | 冻结 DXY `ring_component.recover`（本任务重新导出） | 真实二维 Ring 边界 | 是 |
| CAD 透视视轮廓 | `native.camera.torus_contours(T)` 解析解 | 已知 Torus 的公制投影 | 是（随 T 变） |
| Ring 材料/背景 | Mask 三分类（冻结 INIT 推理） | 投影环应落在真实材料上 | 是 |
| RGB 轨迹 | 冻结 SIFT + `track005` | 多视角特征一致性 | train 侧 |
| held 轨迹 | 每 5 取 1 | **仅评价** | 否 |

## 2. Ring 项：柔性轮廓约束（本任务核心）

对每条 CAD 曲线 `k∈{inner,outer}`，采样 `M=256` 点，计算到**对应** DXY 曲线折线的欧氏距离 `d_k(s)`：

```
d̃ = max(0, d_k(s) - τ_k)          # 柔性容许
E_ring_k = Σ_s w_k(s) · ρ( d̃ / σ_k ) / Σ_s w_k(s)
E_ring = (E_inner + E_outer) / 2     # 内外等权，避免长弧主导
```

- `τ_k`：容许偏差。**统一取 1.0 px**（DXY 椭圆到真实 Mask 边界的实测距离为 0.62–0.63 px，故 τ=1.0 覆盖拟合残差而不放水）。
- `σ_k`：距离尺度，统一 1.0 px，使 `ρ` 接近平方范数。
- `w_k(s)`：可见弧权重。可见=1.0，不可见=0.25（保留先验但弱于真实观测），由 DXY 可见弧支持域给出。
- `ρ`：Huber(δ=2)。

**与 Conic 实验的区别**：不要求 CAD 投影落在椭圆上，而是"落在半径 τ 的管道内即无惩罚"；且按弧长归一化，采样密度不改变强度。

## 3. RGB 项：与冻结 BA 完全一致

沿用 `local_ring_sfm.BA` 的特征重投影（Huber 1 px）+ 正性惩罚 + 时间先验，不做任何修改。
归一化由 BA 自身的 `stats()` 完成，保证与 Ring 项量级可比。

## 4. Ring 区域项

沿用 `_kernels.torus_residual` 的材料/背景项，本轮不改。

## 5. 归一化审计（强制）

| 风险 | 本设计如何处理 |
|---|---|
| 采样点从 128→512 使 Ring 项变强 | 按 `Σ w_k` 归一化，与 M 无关 |
| 内外弧长不等导致内轮廓主导 | 内外各自归一化后等权平均 |
| Ring 残差条数 ≫ RGB 条数 | Ring 项输出固定 2 个标量块（inner/outer），不随点数增长 |
| 视角数增加 | 每视角各自归一化后再平均 |
| τ 被优化器"用尽" | τ 固定为常量，不参与优化 |

## 6. 实验臂

| 臂 | Ring 观测 | BA |
|---|---|---|
| A0 | 原始边界点（冻结 `torus_residual`） | 冻结 BA |
| A1 | DXY 柔性轮廓（τ=1.0，w=可见弧） | 冻结 BA（仅替换 Ring 项） |
| A2 | 同 A1，但 τ 按 `LOSS_COMPONENTS.csv` 预注册扫描选择 | 冻结 BA |

**权重一律固定为 1.0（内外各 0.5）**，不按视频调；A2 的 τ 扫描在合成数据上预注册（见 §7），真实数据只执行一次。

## 7. 预注册的 τ 扫描（合成，仅此一次）

τ ∈ {0.0, 0.5, 1.0, 2.0, 3.0}，在合成 Torus 投影 + 已知位姿上评估：
- 恢复位姿相对真值的旋转/平移误差；
- Ring 残差与 RGB 残差。
选择规则：**取满足平移误差 ≤1 mm 且旋转 ≤1° 的最大 τ**（越大越柔，但不得牺牲位姿）。真实数据不再调参。

## 8. 已知退化解与防护

| 退化解 | 防护 |
|---|---|
| 让 CAD 远离环以减小距离 | Ring 材料区项 + 可见弧权重 |
| 只优化 RGB，Ring 项失效 | Ring 项按弧长归一化后与 RGB 同量级；单独报告 Ring MAE |
| 只优化 Ring，破坏多视角 | held 独立评价；A1/A2 与 A0 同输入同轨迹 |
| τ 过大导致无约束 | τ 上界 3 px，且 A2 选择规则绑定位姿精度 |

## 9. 数值实现

- CAD 曲线：`torus_contours` → 按面积分配 inner/outer（不假设输出顺序）。
- 距离：对 DXY 折线建 KD-tree（每视角一次，缓存）。
- 梯度：交给 `scipy.least_squares` 的 2-point 差分；残差函数输出固定长度（2 个块）。
