## 0. 结论（含对上一轮结论的更正）

1. **上一轮"180° 对称性主导误差"的结论是错的。** 根因是 `make_pose()` 用了 `R=I`，相机朝 +Z 而 Ring 在 +Z 侧，导致所有点负深度；优化器于是落在任意解上。修正 `c2w` 约定后，联合解从大扰动初始化**精确收敛**（法向/偏航/中心误差全 0）。
2. 修复后：**Ring 能定法向与公制尺度，不能定绕环轴 yaw**；RGB 能消歧 yaw；**Joint ≥ 单独任一臂**。
3. 真实 BA（A0/A1/A2）**仍未运行**，本轮只完成合成与单元级验证，不冒充真实结果。

## 1. 三处必须修复的问题

### 1.1 合成相机方向（已修）

`geometry.project` 的约定是 `q = Rᵀ(X−t)`、`depth = q_z`。因此位于 `(0,0,d)` 看向原点的相机必须 `R·e_z = −e_z`。新 `make_pose` 用 `BASE = Rx(π)` 作基准，再叠加 yaw/tilt。

强制断言（每个用例都执行，失败即中止）：

| 断言 | 结果 |
|---|---|
| `R Rᵀ = I` 且 `det R = 1` | 通过 |
| Ring 中心在相机前方（`z>0`） | 通过 |
| 合成三维点正深度比例 >0.99 | **1.000** |
| GT 位姿下重投影与观测一致 | 残差 0 |

### 1.2 RGB 硬截断（已删）

删除 `np.clip(..., -3, 3)`，改为原始残差 + `least_squares(loss='huber', f_scale=1.0)`。
数值梯度在初始重投影偏差 5/20/50 px 时均为非零（`grad_norm_at_init` 见 `metrics/SYNTHETIC_V2.csv`，量级 2.5e4–8.8e4）。

### 1.3 Ring 残差结构（已改）

不再 `mean(huber(e))` 当一个残差。改为逐采样点残差向量：

```
r_i = max(0, d_i − τ)/σ · sqrt(w_i / Σw)
```
- 权重内嵌到残差中，`Σ r_i²` = 加权均值，**与采样密度无关**；
- 鲁棒化交给优化器（`loss='huber'`）；
- 单测：128/256/512 点采样下 Ring 项数值不变（`test_joint_loss.py::test_sample_count_invariance`）。

## 2. 可见弧对应（已修）

## 3. Ring 对称性：影响的自由度

| 自由度 | Ring 是否可观测 | 证据 |
|---|---|---|
| 环平面法向（2 DOF） | **可观测** | 噪声 0.7 px 下 ring-only 法向误差 7.0–11.3°（可收敛但精度有限） |
| 绕环轴 yaw（1 DOF） | **不可观测** | ring-only 在 pert=15° 时 yaw 误差 26.9° |

| 尺度 | 由 Ring 公制提供 | Test B 中 ring 臂固定了公制 |

**RGB 消除 yaw 歧义**：joint 在 pert=15°、噪声 0.7 下把法向误差降到 0.33°、中心 0.27 mm。
