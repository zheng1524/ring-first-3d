# Codex 执行任务｜Phase E3-N0：NeuralFusion 八视角完整融合与官方流程核查

## 一、任务定位与研究者决定

你继续担任 Reference-Ring Anchored Visible-Surface Reconstruction of Polyps 项目的唯一 Codex 执行智能体。

本轮任务是在已有 Phase E3-N0 工作基础上，完成一次**遵循官方完整流程的多视角 NeuralFusion 重建实验**。

研究者已明确决定：

1. 不再因为单视角 F0 表现不佳就提前宣布 NeuralFusion 失败。
2. 首先使用视角分区选出的 **8 个视角**完成逐步融合。
3. 保持 NeuralFusion 官方预训练权重、融合机制和正常推理流程，不进行额外网络训练。
4. 同步核查 Mesh 提取与渲染问题，但不因排查问题而打断正常融合。
5. 按照实际清理后的物理范围，为每个实验组独立确定合理的公制三维网格。
6. 额外选取 G06–G08 中一个数据质量较高的实验组，验证方法的可迁移性。
7. 为后续 **20–30 视角增强采样**建立候选清单和执行方案，但本轮暂不自动运行增强实验。

本轮已授权八视角预训练 NeuralFusion 推理及必要的工程修正。

**禁止重新训练网络、修改预训练权重或根据输出好坏进行无边界参数搜索。**

## 三、严格遵守官方 NeuralFusion 完整流程

研究者怀疑此前的 F0 可能没有正确经过官方的体素特征到表面转换流程。

本轮必须重点核查，但不需要单独开展复杂消融。

官方参考：

https://github.com/weders/NeuralFusion

### 3.1 核查完整执行链

按照官方实现验证以下步骤：

1. 输入真实 HERO 原生深度、有效 Mask、相机参数。
2. 利用相机位姿将观测映射到统一三维坐标。
3. 提取当前视角对应的局部潜在特征。
4. 执行官方 Fusion Network。
5. 将特征更新写回全局 latent volume。
6. 执行官方 Translator Network，将 latent 特征转换为 TSDF。
7. 使用正确的等值面提取方法（Marching Cubes）生成三角 Mesh。
8. 保存未经自定义几何优化的原始重建 Mesh。
9. 最后进行项目自己的可视化和定量评价。

**必须实际执行 Translator Network，不得用占据体素立方块、latent 特征阈值或直接堆叠点云代替其输出。**

若官方 `test.py` 的数据加载和数据库初始化依赖 GT，可沿用已批准的无 GT 适配层，但必须保留上述官方算法链。

不得为了直接运行官方脚本而引入真实 GT 或 Oracle 信息。

### 3.2 Mesh 输出检查

核查：

- TSDF 是否来自真正的 Translator 输出；
- Marching Cubes 是否正确执行；
- 是否保留插值得到的浮点顶点坐标；
- 三角面拓扑是否有效；
- 体素坐标是否正确转换为毫米世界坐标；
- 网格法线是否正确；
- 是否存在直接输出占据立方块的情况；
- 是否存在未知区域被错误赋值后产生虚假封闭的问题。

同时保存：

- 原始 latent/count 的必要统计；
- 原始预测 TSDF；
- 原始 Marching Cubes Mesh；
- 平面着色 Mesh；
- 使用相同顶点和面片的平滑法线着色 Mesh。

平滑着色仅用于检查显示差异，**不得将其当作几何精度改善**。

不允许通过任意 Mesh smoothing、缩面、补洞或大规模删面来伪装网络效果。

## 四、首轮八视角正式融合

### 4.1 重新确认八视角名单

使用最新的相机分区与 Camera Gate 资产，从现有可用参考中选取 **8 个视角**。

选择原则：

1. 尽可能覆盖不同的相机位置和观察姿态。
2. 保证各主要视角分区都有代表。
3. 优先使用合格、可靠的相机和 HERO 深度。
4. 避免大量选择几乎重合的视角。
5. 保留历史条件性相机身份，不得把它们写成已严格认证。
6. 不得根据 NeuralFusion 最终 Mesh 的好坏反向挑选视角。

原先 ref08、ref13、ref03 等已知 CORE 可继续作为重要基础，但必须按照最新版本重新核查。

原有六视角顺序可以作为历史参考，不能直接补两个视角就称为新的八视角正式设计。

**先冻结八视角名单、所属分区、相机资格、顺序和理由，再开始推理。**

若某视角不满足最新规则，应按当前项目允许的条件性使用制度处理并记录风险，不得静默套用旧资格，也不得为了凑足八个而伪造合格身份。

### 4.2 完整执行八视角融合

按照冻结顺序：

- F0：第 1 个视角；
- F1：前 2 个视角；
- F2：前 3 个视角；
- ……
- F7：全部 8 个视角。

全程使用同一物理世界坐标和同一个全局潜在三维场。

各阶段保存可以复现的重建状态。

**不要因为 F0、F1 或某个中间版本块状明显、表面粗糙或部分指标不佳就提前停止。**

本轮最重要的科学问题是：

> 随着真实不同视角持续输入，官方 NeuralFusion 是否能逐步改善息肉的三维表面？

只有出现程序错误、物理尺度损坏、错误相机变换、无效数据进入网络或其他会使实验失去意义的工程故障，才应暂停修复。

不得将预设的几何评价阈值作为提前终止整个八视角实验的理由。

### 4.3 保留逆序对照

完成正式八视角流程后，使用相同八个输入，以严格逆序重新初始化空 latent/count 并融合。

其他变量保持一致。

报告顺序变化对几何的影响。

不得从两个顺序中选择较好结果再冒充唯一主实验。

## 五、输入裁剪、物理网格与清理

### 5.1 裁剪

沿用人工批准的原则：

**各视角独立等比例裁剪，再适配 320×240。**

以 Polyp 和可见 Ring 引导 ROI。

必须保证：

- RGB、深度、Mask 同步；
- K 根据实际裁剪和缩放正确更新；
- Padding 和无效深度保持无效；
- 不使用虚假深度填补未知区域；
- Ring 遮挡关系正确；
- 息肉头部、细柄、边界有效信息保留；
- 反投影结果与原始毫米世界坐标一致。

Mask 裁剪本身已有较可靠的历史验证，原则上直接复用，不开展无依据的大范围参数搜索。

不得恢复已经被人工明确取消的“3px 细柄保护门槛”。

### 5.2 最新多视角清理

复用已经批准的最新清理技术，包括相应 A2 多视角投影证据。

本轮重点是让现有成熟清理流程一致地作用于每组输入。

不再重新发明一套清理算法。

所有清理均在派生输入副本上执行，原始 HERO 深度和原始 XYZ 保留。

对未知、遮挡或没有可靠反证的区域，不得把“没有支持”直接等价为“应该删除”。

记录每组的 Raw、Cleaned 数量和主要删除类别。

### 5.3 按实际大小建立物理网格

G01 与第二实验组分别计算清理后主体及 Ring 的有效毫米范围。

根据实际几何包围范围确定共同物理网格：

- 保留完整可信息肉；
- 包含已知 Ring 和必要的空间余量；
- 避免大量无意义远端空间；
- 不裁断真实头部、细柄和合法侧面；
- 在观察 NeuralFusion 输出前冻结物理网格。

使用与官方模型配置一致的潜在网格维度及尺度归一规则。

记录：

- 世界原点；
- 毫米范围；
- 模型归一化映射；
- 体素边长（mm）；
- Ring 尺寸逆映射结果。

不得通过改变坐标比例让结果看起来更加平滑。

## 七、错误封闭与真实三维可视化

研究者允许 NeuralFusion 根据已学习的形状先验推断未观测表面。

因此：

**不得因为网络生成了未被 HERO 直接观测的表面，就自动删除或阻止融合。**

但必须在评价和展示中区分：

1. 有真实输入深度支持的表面；
2. 主要由网络推断、缺乏直接观测支持的表面；
3. 未知或不能可靠判定的区域。

类别判定应依据观测覆盖、相机可见性和真实深度支持，明确其近似性质，不能把网络推断当作实测真值。

特别记录：

- 错误封闭；
- Ring 遮挡区的虚假表面；
- 头部和细柄的连接情况；
- 重复层；
- 侧面新增；
- 主面收缩；
- 与真实图像 Mask 明显矛盾的表面。

**以上均用于评价，不通过提前删面改变官方融合结果。**

可视化使用统一毫米尺度、统一相机和固定 Ring CAD 实体。

至少生成四张核心复合图：

**Figure 1：** 八视角来源、分区、清理后深度、裁剪与相机几何。

**Figure 2：** 原始 HERO、历史 Open3D、NeuralFusion F0–F7 的统一三维对照。

**Figure 3：** F0、F2、F4、F7 的主体与侧面局部细节；同时核查原始 TSDF→Mesh 和渲染差异。

**Figure 4：** 真实图像对照、跨视角首次表面投影、错误封闭、已观测与推断区域区分。

每个正式版本保存真实 Mesh 文件，不得只提供图片。

## 九、评价原则与禁止事项

本轮统一评价三个独立维度：

**光滑、完整、真实。**

不得因为表面更光滑就认定几何更正确。

不得因为删去大量困难区域导致指标提高，就认定融合成功。

必须保留：

- 原始 HERO；
- 历史 Open3D；
- 最新清理输入；
- NeuralFusion 每阶段原始输出。

重点报告：

1. 表面连续性和块状程度随视角数量的变化；
2. 原有主面保留情况；
3. 重复层与接缝变化；
4. 新增可信侧面；
5. 错误封闭和未经观测支持的推断表面；
6. 网格尺度及分辨率；
7. 原始 TSDF 与 Mesh 提取是否正确；
8. 真实图像的首次表面投影解释能力。

不使用 GT/Oracle 选择模型、筛选视角或调参。

不修改 DXY 主线、Ring-First、HERO 权重及已经冻结的历史技术资产。

不启动新网络训练。
