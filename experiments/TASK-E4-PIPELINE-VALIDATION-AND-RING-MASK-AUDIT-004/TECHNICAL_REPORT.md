## 8. 三个核心问题的回答

### Q1. Ring-First 是否应采用 DXY 风格的最大连通域观测？

**不应作为默认，应作为"带记录的诊断分支"。**

- 收益明确但极窄：78 个视角里只有 4 个多分量，只有 1 个真正被污染到超过 3 px（G05/005，9.451→0.748）。
- **会破坏其他真实 Ring 的可见弧信息**：G02/004（1.915→1.936）与 G02/005（1.589→1.766）在 M1 下**变差**，因为被丢弃分量在那些视角带走了有效弧段；这两例被分类为 `LIKELY_NOISE_TINY`，但**没有任何证据证明它们真是误分割**。
- 观测层选择会改变残差分母（C4 陷阱）：G05 上 M0 的 128 点里 113 点主环 / 15 点孤立块；全边界则是 335 / 48。**"MAE 下降"必须同时给出被排除点的残差（76.05 px）与被排除面积（0.63%）**，否则会把"忽略难拟合区域"误报为"几何精度提高"。
- 正确的移植点是 **DXY 的小孔填充（单侧、只加环、不动息肉）**，而不是连通域删除；后者必须保持"原始标签不动 + 只改观测 + 记录被排除分量"。

### Q2. 哪些门控必要，哪些可能过严或缺乏证据？

| 门控 | 判定 | 依据 |
|---|---|---|
| 输入维度/标签取值/K 可逆 | **I 必需契约** | 违反即无法计算 |
| HERO 深度有效像素 >0 | **I 必需契约** | 无有效深度则无下游 |
| Ring MAE ≤3 px | **II 有证据但只对 Ring 对称有效** | 77/78 通过；唯一失败是真污染；但**检测不到 yaw 翻转**（G03 v0/v1 都在 0.6–1.1 px） |
| RGB PnP ≥6 内点 | **II 但覆盖代价高** | G05/005 两个视角 0 内点直接终止实例；是覆盖损失的主因 |
| `validation_min_test=8` | **III/V 经验值，直接搬运会全军覆没** | 本数据 held 轨迹 18–146 条，按 V6 规则几乎全判"证据不足" |
| held MAE ≤3 / p95 ≤6 | **III 需重标定** | 本数据 BA 最好解也只有 G06 达到 3 px；说明阈值来自另一数据分布 |
| 中心离散 ≤2 mm | **III** | G06 v0/v1 差 44.5 mm 仍选出可用解；该阈值对本数据无区分力 |
| 旋转离散 | **IV→应升级为诊断主项** | 本数据 165°–176°，是最强失效信号，却未被任何门控使用 |
| 3 px 以外再加"实例级终止" | **V 重复且有害** | G05/005 因 2 个视角失败而丢掉 5 个可用视角 |
