# Phase E3-N0｜Gate B/C/D 展望与独立授权界限

日期：2026-11-02；**均为 `NOT_APPROVED`**。此文不是Codex执行指令。前置Gate A只解决权重/输入/单位/GT隔离，不证明预训练模型在内镜域可用。

## Gate B｜正式最小预训练融合（待批准）

**输入**：Gate A冻结的六源原始资产与统一Crop/K/模型公制映射，使用其批准的主checkpoint、完全相同的空latent/reset规则。此阶段实际只让三CORE进入模型：

| 版本 | 累积顺序 | 目的 | 失败停机 |
|---|---|---|---|
| F0 | ref08 | 确认单来源能产生可解释主可见面 | 若比例/位置/原面覆盖严重失真，不自动推进F1 |
| F1 | ref08→ref13 | 观察两源跨视角接缝和首层变化 | 出现广泛错误闭合或裁剪域异常，停止定位 |
| F2 | ref08→ref13→ref03 | 三CORE统一场 | 不能以F1/F2好看掩盖F0失败 |
| F2_REVERSE | ref03→ref13→ref08 | **同源**反序对照 | 必须独立清空latent/count，固定所有非顺序变量 |

Matched Open3D在相同经过裁剪的输入、相同Mask/K/世界坐标及同前缀运行一个预注册固定参数对照；另外保留历史D0未裁剪SINGLE/G0/G1仅为历史证据。历史D0严格门禁仍为FAIL；matched Open3D不是为神经方法挑选较差参数的工具。若F0不合格，匹配Open3D可完成有限诊断但不自动进入新视角。

### Gate B 验收

按三列报告“真实、完整、光滑”：固定合法首层射线的AGREE/MISS/NEAR/FAR/CAD/UNKNOWN；原始三CORE完整Face/面积保存；新增有观测支持侧面；封闭碎片/开放边/最大分量面积比/接缝法向。至少要列出：主面保存率是否不劣于同条件Open3D、首层是否没有D0式大退化、未知域是否被伪装成零面、F2正逆序是否显著不同。**科学上不得仅凭单个定量阈值声明物理准确**。F0/F2输出真实未删Mesh、GLB、固定四图、源码/配置/SHA、运行时间及峰值显存；F1和reverse同样保存Mesh/指标。若严重缩面或重复层，负结果作为完整交付；不重训权重修复。

**Gate B必须单独由研究者授权预训练前向和相应GPU资源。** 如果Gate A发现旧Torch与GPU/驱动不兼容，可申请隔离环境的有界兼容工程任务；不得自动转GPU、pip升级主工作区或修改网络结构。

## Gate C｜新增观察方向与完整逆序（待批准）

只有人工审阅Gate B的F0–F2及逆序后才讨论：

| 版本 | 追加源 | 资格与增量科学问题 |
|---|---|---|
| F3 | growth_r04（B3） | 已覆盖方向的冗余桥接是否减少接缝，或引入错层；其Ring及两条图像关系支持不等于认证 |
| F4 | new_r00（B1） | 新方向能否增加有条件可见侧面；Ring略超容差，可能有原生远端异常 |
| F5 | growth_r14（B4） | 最弱独立相机资格下的新方向；独立Camera Gate不足不能忽略 |
| F5_REVERSE | r14→r00→r04→ref03→ref13→ref08 | 同六源不同顺序，以检验在线潜在融合顺序依赖 |

如果在F3发生几何退化，先停在F3审阅；不因研究者曾写过F5计划就继续。如果F4/F5失败，不将条件性相机自动判错，也不因为它们使Mesh更漂亮就认证相机。必须报告每一新增源相对前缀的同分母变化、相机不确定、源Raw的独有结构和真实反证。优先留出有独立条件相机身份的未融合目标用于真实投影，区分IN_SAMPLE/HELD_OUT_WITH_SHARED_UPSTREAM；绝不能假称严格盲测。

用户与RA另外批准时才做：冻结模型、分辨率、来源与顺序；比较原Masked HERO vs 在**派生输入副本**上对可靠、明显的真实跨视角Polyp Mask越界做保守处理。必须在像素/原face可追溯范围内区分：相机资格、Ring遮挡、未知视角、边界容差、可能细柄、Depth前后层。E3-C的FREE_SPACE_CONFLICT不可作为真错误面全局硬删除；不能通过删掉难的主面改善曲率或最高近邻率。先只读批评，硬删另请批准。
