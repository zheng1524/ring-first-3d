# MAINLINE_REPRODUCTION

## 唯一入口

```bash
python tools/run_w0_camera.py --group G03 --video 005 [--dry-run|--stage all|b0|w0]
```

阶段：prepared views → Ring-First → **frozen tracks（缺失时报错，非静默回退）** → B0 → W0 → 评价 → Gate → 导出。
无按组分支；`--group/--video` 只选择输入。

## B0 / W0 定义（与 012 一致）

- B0：Ring-First v0 初始化 → 冻结 BA（`BA_max_nfev=60`）。
- W0：**从 B0 相机热启动，重新三角化训练点，再跑同一 BA（30 次）**。不是新损失。

**结论**：RGB 回归完全一致；Ring 两项因距离实现不同不可直接比较（已在 ERROR_FIX_LEDGER 记为未闭环项）。
