# 一、核心研究目标

此前的研究已经证明：

1. Ring-First 可以为局部重建提供物理尺度和相机几何约束。
2. MVSAnywhere HERO 能够生成具有实际来源的局部三维可见表面。
3. 单参考面存在明显的表面缺失。
4. 不同参考之间存在深度错层和几何冲突。
5. 历史简单叠加、主体优先补片和过度严格的去重规则均未充分利用不同观察方向。
6. 仅利用 G01 原有六个参考面，得到的新增表面仍然有限。

本轮正式改变研究组织方式。

**不再把所有参考面直接当作需要融合的对象，而是先分析真实相机观察方向，将不同观察区域分配给局部重建，再通过相邻视角建立空间联系。**

# 七、Batch D：视角负责制的选择性点云聚合

这是本轮的主要最终目标。

## D1：基本思想

不同方向的局部重建不需要全部平均。

**每个观察方向的可见区域，由最适合解释该区域的局部重建负责。**

其他来源可以：

- 补充新的可见区域；
- 提供重复观测支持；
- 形成可信的配准对应；
- 记录几何冲突；
- 提供未知区域证据。

不要求把全部局部表面焊接成一个Mesh。

## D2：区域负责制

对于某个可见方向区域：

优先综合：

- Cleaned有效面积；
- 实际相机观察角度；
- 可见方向覆盖；
- 局部连续性；
- 法向可靠性；
- 相邻位姿可靠性；
- 多帧真实图像支持。

确定负责该区域的局部块。

默认由最有证据的来源承担正式显示。

**但不能因为其他来源与负责块存在一定深度差异，就直接拒绝全部新表面。**

应先判断其是否属于：

- 已解释区域；
- 新观察区域；
- 遮挡区域；
- 几何冲突；
- 未知。

## D3：反向投影

复用：

- 真实XYZ；
- Z-buffer；
- Ring CAD遮挡；
- 源像素邻接；
- 原始有效三角面；
- 实际相机位姿；
- Polyp Mask。

将已有负责块投影到邻接真实相机视角。

分类：

的新增点云。

不得仅因面积小而拒绝。

## D5：三级聚合输出

### F1：Multi-Block Point-Cloud Display

多个局部块直接共同展示。

每个块保留身份。
