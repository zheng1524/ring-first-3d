# TASK-BOUNDARY-GUIDED-SURFACE-GROWTH-001

## 一、正式研究任务

继续当前 Ring-First 三维重建项目。

研究者已审阅：

`TASK-VIEW-PARTITION-MAST3R-FUSION-001`

并人工确认了新的研究方向。

**本任务已经获得批准，请直接开展实验。**

新方法：

**Boundary-Guided Incremental Surface Growth**

中文：

**可信边界引导的增量式可见表面生长。**

核心目标：

> 不再追求多个完整参考面之间的整体融合，而是以已有可信表面为基础，沿真实观测边界逐步接受新视角提供的连续补片。

主要流程：

```text
已有可信主面
    ↓
定位实际可见表面边界
    ↓
寻找能够观察该边界外侧的新视角
    ↓
复用已有或新增 HERO 三维重建
    ↓
提取候选新表面
    ↓
识别与旧表面的连接带
    ↓
去除重复展示部分
    ↓
只接纳边界外的新增连续面
    ↓
更新可信表面和生长边界
    ↓
继续寻找下一视角
    ↓
直到现有有效数据不再提供可接受的新表面
```

**本轮核心不再是融合更多点，而是让新面从已有面的边缘向外延伸。**

本轮允许修改 P8 的选择性聚合逻辑。

不得直接沿用旧 F2 的逐点接纳方式作为唯一算法。

- 已接受的新增面可以成为下一轮的生长起点；
- 可以主动寻找更多视频参考帧；
- 可以尝试连续多轮增量生长；
- 可以改进边界识别与局部几何接纳；
- 可以利用真实重叠带进行有限配准；
- 不要求所有面片焊接成单一 Mesh；
- 不以历史 0.3 mm 或 3 px 门槛一票否决补片。

仍然冻结：

- 原始 P0；
- Ring-First；
- HERO 权重；
- 原始相机资产；
- Ring CAD；
- 正式 Dxy 主线；

允许生成新的派生参考、位姿和点云。

不使用 GT/Oracle 选择算法。

所有原始 XYZ 保留，几何修正必须作为独立派生变换保存。

# 四、P1：建立当前可信表面的生长边界

对当前已接受的面片集合：

\[
S_k
\]

提取开放 Mesh 的实际边界。

优先利用原始三角面拓扑：

**只被一个有效三角面使用的边，可以作为边界候选。**

1. 有效观察终止边界；

4. 清理产生的内部孔洞；

- XYZ；

- 对应像素；
- 相机观察方向；
- 已有邻接面；
- 边界可靠性；
- 是否存在其他视角支持。

建立：

`GROWTH_FRONTIER`

作为后续新视角选择与新面接纳的基础。

优先关注真正的外部可见面终止边界。

不要通过平滑或补面创造边界。

# 五、P2：从新参考中提取边缘延伸补片

这是本轮核心算法。

对新的参考面：

\[
P_j
\]

首先复用旧 F2 的真实反向投影和可见性分类。

然后增加**边界引导的区域判断**。

## 5.1 连接带

寻找候选面与已接受面之间有可信空间对应的重叠区域：

`OVERLAP_ANCHOR`

连接带主要用于：

- 判断空间位置；
- 检查法向；
- 比较局部深度；
- 估计相邻面关系；
- 寻找合理的接缝。

**连接带不需要重复加入最终场景。**

不要再将整个新参考中与旧主体重合的曲面显示出来。

## 5.2 新增区域

从连接带出发，在原始参考的有效三角面和源像素邻接上向外扩展。

得到：

`FRONTIER_EXTENSION`

重点检查：

- 是否超出现有可信表面的投影覆盖；
- 是否向原本缺失的观察方向延伸；
- 是否在源参考中连续；
- 是否具有真实 RGB / Mask 支持；
- 是否被 Ring 遮挡；
- 是否存在明显深度冲突；
- 是否能够解释其他真实观察帧。

新增区域必须有原始三维来源。

不能仅凭空间插值制造新的表面。

## 5.3 冲突区域

对于与旧面重叠但深度明显不同的区域：

`OVERLAP_CONFLICT`

不要直接加入最终展示。

但也不能直接作为错误点删除。

保留冲突区域与其来源，作为后续局部配准诊断。

## 5.4 接缝附近的有限几何调整

如果候选补片具有连续真实来源，而且重叠带显示出小范围的系统性错位，可以尝试：

- 基于连接带的局部刚体配准；
- 稳健 point-to-plane / GICP；
- 必要时单独测试低自由度局部法向偏移。

不强制使用所有方法。

优先采用能够解释具体错位的最简单方法。

要求：

- 已接受的主面保持冻结；
- 优化只作用于候选补片或其派生变换；
- 不用错误的整片密集面驱动配准；
- 保留原始几何和修正候选；
- 不用 GT；
- 不为了消除深度错层任意拉伸或变形。

若接缝无法合理对齐，但新区域本身有真实观察支持，可以保留独立开放点云块，明确标记为尚未连接。

# 六、P3：真正实现增量式生长

这是与历史 F2 最重要的区别。

当前 F2 主要依赖来源排序和一次性反向投影筛选。

本轮新增：

**已接纳面片成为下一轮有效的场景边界。**

执行：

\[
S_{k+1}=S_k\cup\Delta S_k
\]

每接受一块面：

1. 将其作为新的来源面片加入场景；
2. 保留原始点与三角面身份；
3. 更新已解释区域；
4. 更新可见性和遮挡；
5. 重新计算实际生长边界；
6. 将该新增区域纳入下一轮参考选择；
7. 继续寻找沿当前新边界延伸的表面。

不得仅在最初主面上反复叠加新参考。

先将 G06/G07/G08 作为方法验证基准。

分别以已认可的新增面为起点。

检查原始视频中是否存在进一步观察该新边界的相机视角。

优先复用：

- 当前视角分区；
- MASt3R 匹配；
- Ring约束相机；
- 历史视频帧；
- 冻结 HERO；
- 已有新参考推理结果。

**本轮不再限制每段视频最多新增一个 HERO 参考。**

但必须优先检查尚未利用的视角，避免大量生成几乎重复的参考。

采用增量式执行：

1. 排序所有可用的新视角；
2. 选择最可能观察到当前未恢复边界的参考；
3. 尝试新 HERO 推理；
4. 提取新增补片；
5. 更新场景；
6. 再选择下一参考。

逐轮记录实际增益。

不要预先假设需要几个参考。

在现有数据允许的条件下，持续到没有新的有效观察方向、有效候选已经检查完毕，或连续新增结果不再具有可接受的几何收益。

如果视角或相机条件不足，明确记录未能继续的原因。

不得将数据不足冒充算法失败，也不得将无认证的点云作为已验证新增面积。

# 十一、量化指标与验收

本轮不要以总点数为主要指标。

重点记录：

### 1. 边界增长

- 当前可信面边界长度；
- 可以扩展的边界长度；
- 新补片与旧面的连接带长度；
- 接缝几何距离；
- 新增连续原始三角面面积；
- 最大新增完整面连通分量；
- 新增面来源；
- 独有可见方向。

### 2. 重复消除

- 新参考原始点数；
- 用于连接的重叠点；
- 被排除显示的重复点；
- 真正新增点；
- 冲突点；
- 无法判断的点。

### 3. 逐轮收益

每一轮记录：

\[
\Delta A_k
\]

即该轮新增完整原始面面积的代理量。

同时报告：

\[
\Delta C_k
\]

即独立真实视角下的新增可见覆盖。

面积代理不得冒充已经认证的真实新增解剖面积。

### 4. 原有可信面保护

- 冻结主面点数是否不变；
- 已认可新增面是否保留；
- 是否出现新的重叠层；
- 是否损伤旧主体；
- 是否形成不合理的穿插。

### 5. 人工验收

每组必须提供：

`ACCEPTED / CANDIDATE / CONFLICT / REJECTED`

四种状态。

研究者可基于实际可视化进行进一步确认。

人工认可可以用于工程继续生长，不等同于物理精度GT。

# 十二、停止条件

本轮希望尽可能充分利用现有有效数据。

但不允许通过无边界参数搜索制造增长。

单个视角生长分支在以下情况停止：

1. 当前有效视角无法观察新的未恢复区域；
2. 新参考只能提供重复表面；
3. 候选补片缺乏实际来源；
4. 无法建立具有意义的空间连接；
5. 新增区域主要是异常拉伸或严重冲突；
6. 所有有效候选视角均已检查。

某一场景停止不影响其他场景继续。

必须区分：

`DATA_EXHAUSTED`

`NO_VALID_NEW_VIEW`

`RECONSTRUCTION_FAILED`

`REGISTRATION_FAILED`

`PATCH_REJECTED`

`GEOMETRIC_CONFLICT`

不能统一报告为融合失败。
