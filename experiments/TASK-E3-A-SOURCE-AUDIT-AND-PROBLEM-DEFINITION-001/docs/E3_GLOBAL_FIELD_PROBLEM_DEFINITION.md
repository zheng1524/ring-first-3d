# E3 全局隐式问题定义（未求解）

待求函数为 `Phi:Omega_G -> R`，并配套证据身份 `U(X)` 与未校准不确定性代理 `sigma(X)`。整个固定 ROI 有定义表示任意域内点都能得到有限标量及身份，不表示每处都有观测、具有唯一几何、已经形成封闭解剖实体，或满足欧氏距离性质。未验证距离性质前统一称 **implicit scalar field**。

## 固定 ROI 与坐标

每段视频一个独立域。精确边界、Polyp 包络、全部候选包络、CAD、中心和 margin 见 `config/GLOBAL_ROI_FROZEN.json`，在本轮几何诊断前冻结。规则为：全部**参考相机已筛查**的原始顶点与完整 CAD 的 AABB，向各轴外扩 `max(2mm,0.25×CAD外径)`；不作分位裁剪，不删除长尾以缩小域。G07 没有通过筛查参考，使用全部候选包络仅作为压力审计域，不能冒充正式合格 ROI。候选域与参考筛查域均披露。

世界单位毫米，Ring CAD 近中心为局部原点，轴向为 CAD Z；所有源到该视频局部世界的映射为现存归档坐标下的 identity。完整 c2w/K/来源 SHA 单独保留。Ring 中心、网络数值归一化中心和 `Phi=0` 是三件事。未来可用冻结 affine 数值归一化，但必须可逆并给出尺度的距离/梯度转换，不得调相机或把 Ring 中心指定为息肉表面。

G01_004 与 G01_005 是同一物理组但两个未获跨视频统一认证的坐标系。历史 pose_graph 的操作性 unified 标记不等于认证；现存 `CROSSVIDEO_GATE.json` 明确 `fusion_certified=false`。Ring 的旋转对称性不能解决 yaw。三张照片 K/c2w 未认证，不能建立公制局部场。

ROI 外扩是研究域安全余量，不是已验证的完整解剖包围盒或相机误差界。额外源/认证边界需要变更时必须在未来任何新预测之前重新登记独立 benchmark 版本，不能随输出收缩。

## 身份场与不确定性

| U / 附加状态 | 数学和证据含义 | 是否可计为真实可见面积 |
|---|---|---|
| OBSERVED_SUPPORTED | 原始来源身份、同物体和合法可见性支持的表面 | 仅在对应资格层级内，不能升级成 GT |
| SINGLE_VIEW_SUPPORTED | 一份合法来源独有支持，其他视角没有有效反证 | 单独报告，不因只有一票删除 |
| FUSED_CORRECTED | 有来源、有依据且修改前后可追溯的融合修正面 | 独立列修正量、预算与来源；条件性 |
| PRIOR_INFERRED | 由形态先验主导而非直接观察确定 | 否，独立推断分母和不确定区间 |
| CONFLICT_UNRESOLVED | 多份候选证据不能判定相同物理面或相容性 | 不作为认证真面；必须保留候选和原因 |
| CAD_OCCLUDED | 某源的视线被已知 CAD 截断 | 不能由此推出后方空无 |
| UNKNOWN | 无足够合法观测或符号资格 | 否；有限 Phi 数值也不改变此身份 |

`sigma` 至少记录来源数/家族数、相机条件、最近原面距离、局部法向/拓扑风险、可见性冲突与先验依赖；未校准前不能解释为置信概率或毫米标准差。全域数值延拓允许不唯一；Unknown 中的零面必须屏蔽认证，未知取值的正负不能被用作自由空间事实。显式保留 evidence-list 可以表达一个来源可见、另一个来源被遮挡的并存情况。

## 何时允许同表面融合

同一合格局部坐标、完整来源/相机链、相容物体身份、可见性次序无矛盾、没有明确 CAD 穿插，并有**独立对应或足够表面身份依据**，才成为同表面融合候选。投影重叠、低深度差、像素循环误差小、法向近似或历史匹配模型输出均不能单独认证物理同一性。本轮认证的同表面冲突数为0，不能将候选残差直接变成几何纠错监督。

A 同表面深度冲突、B 不同表面/遮挡、C 对应未决必须分列。B 可互补不焊接，C 可拒绝融合；不得把两层数值平均为中间第三层。相机不确定的源只能作压力/条件诊断，不能迫使其与主面一致。共享上游 RGB 的 Raw/Cleaned/F1/F2/F3 也不能重复投票。

## 不指定算法的可证伪优化问题

未来问题可写成约束集合：最小化合法观测的**类型相容**残差、接缝和正则，同时满足固定观测存活、可信面迁移预算、CAD 非穿插、来源追溯和推断身份分离。这里只定义要求，不规定 G0/G1、网络或聚合算子。

Projective 观测应通过候选零面的源视角首交/深度约束比较；UDF 观测可约束候选面与原面的位置/绝对距离。不能直接令同一个欧氏 `Phi(X)` 同时等于来自不同视角的轴向 delta。Eikonal 仅适用于获得相应距离/符号资格的全局函数，不能对 projective delta 直接施加。重距离化必须另测零面漂移，不能用距离性质改善掩盖表面移动。

高可信冻结面应在表示/硬约束中存活；未来 source-ray miss 必须仍留在固定分母并计代价。离散命中数量是验收门禁，不是可微损失。小标量残差幅度不能保证零面的位移小，尤其 `|grad Phi|` 很小时，必须跟踪真实面位置和每源首交。无来源的漂亮闭合面不构成成功。

## 两类缺失的可执行判据

`OBSERVED_BUT_UNRECONSTRUCTED`：合法源图像有 Polyp Mask/外观证据而没有可靠原面首交/连续结构。必须保留完整像素分母、具体 UV、原面空缺/断裂原因；没有深度时不能将该像素映成已知三维孔洞。本轮原面首交缺失包含边界栅格与三角面连通缺口，不能全部叫 HERO 没有预测点。

`TRULY_UNOBSERVED`：对于被定位的候选实体区域，全部认证视角的可见性分析证明无法直接观察，且相机、遮挡和区域身份足够完整。仅在所有相机外、CAD 后方或无窄带证据，可证明“这份目录不直接约束该位置”，不能证明那里存在特定隐藏解剖面。当前没有完整解剖表面和全链路可见性真值，因此不认证任何息肉背面区域为确定 Truly-Unobserved。

`UNKNOWN_OR_INSUFFICIENT_EVIDENCE`：以上条件不足、首面次序矛盾、来源身份/相机有条件、隐藏位置未定位时的合法结果。未来条件先验必须输出多个候选、形态敏感性和 PRIOR 身份，不进入已观测面积/体积。当前未执行形态推断。
