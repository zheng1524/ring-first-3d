# E3 假设预注册与后续接口

本文件冻结可证伪问题，不选择 G0/G1 或具体 LocalField。所有后续执行仍待 PM。当前模型前向、新 HERO、训练、融合优化、几何形变次数均0。

| 假设 | 同输入比较与成功证据 | 证伪 / 停止条件 |
|---|---|---|
| H1 局部表示能忠实保留原观测 | Projective narrow-band、Mesh signed/unsigned narrow-band、surface-only；同原面/相机/ROI/查询点与八项资格测试 | Unknown被赋实体符号、开放边界伪闭合、原零带偏移、CAD后负票、来源不可追溯 |
| H2 可见性语义优于仅support | support → +occlusion → +free-space → +Mask/Ring/来源相关性；相同证据预算 | 独有侧面丢失、错误自由空间否定合法遮挡、仅图像误差下降而覆盖下降 |
| H3 全域场可以在硬存活约束下表示多源 | 稳健非学习全域拟合、HERO锚定局部/神经残差、条件推断；方法和预算须新审批 | E2.7式收缩、超出原面迁移预算、强平均真实不同层、认证无来源表面 |
| H4 新视向确实增加几何支持 | 全筛查源集合 vs固定代表集；分别报告相机格/法向格/空间格与家族 | 只有相机角度扩大或重复票数上升，无来源连续面增益 |

| H6 隐藏形态只能条件推断 | Unknown对照、多候选先验、观测面冻结、不确定性/测量敏感性 | 将先验面积算作观察覆盖、单一背面被称真实、利用GT挑形态 |

E3-B 建议比较局部 Projective、Mesh 有向/无符号窄带与必要 surface-only 退路，先用冻结小查询集合再使用原分母射线。不得预选赢家；真实细柄和真实双表面缺人工标签时只报告资格局限，不能制造 PASS。

E3-C 建议采用 H2 的四层可见性消融，使用同输入/同预算，不调用原生 V-FUSE 网络，不将其论文或 RA 推荐当现成迁移证据。本轮未下载权重、未独立复核外部论文实现；设计依据只是所附 RA 原文。

E3-D 建议在 E3-B/C资格通过后比较 H3；完整有限标量域、观测来源身份、覆盖保护为共同要求。当前相机/对应限制可能使统一面不可辨识，允许拒绝融合和有来源开放图册。Unknown/先验单独评价。具体求解器、权重、步数和方法胜负均未决定。
