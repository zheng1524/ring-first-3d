A `SAME_SURFACE_DEPTH_CONFLICT` 认证数=0；B `DISTINCT_SURFACES_OR_OCCLUSION` 仅认证“固定CAD在候选之前”的数值次序，不认证后方为真息肉面；C `CORRESPONDENCE_UNRESOLVED` 保留其余可投影候选。低循环误差/大深度差不能把C升成A。B中的正Mask矛盾仍需解释，不能自动称合法遮挡。按案例的实际分类数：

E1系统性偏差和E5错误重复面目前均缺认证对应真值。E2统计投影分离候选；E3统计max-edge/像素足迹>8原面；E4统计面积<最大组件1%的小组件；它们不是已确认错误率。E6是全Mask内无原面首交像素，可能是栅格边/连通缺口而非无XYZ；E7另列正Mask/CAD矛盾。E8未知空间不等于已定位的隐藏解剖面；E9明确来源/相机/对应未决。所有分母与级别见 `E3_ERROR_TAXONOMY.csv`。

历史损失分两层：`E3_HISTORICAL_FACE_RETENTION.csv` 统计同一原face-ID的保留/省略面积与保护代理；`E3_HISTORICAL_SOURCE_RAY_COVERAGE.csv` 用现存F1/F2/F3几何和冻结相机查询全部源Polyp像素，记录原有效首交现在miss及替代交点偏移。没有运行新的融合。省略重复原面不等于丢真实覆盖；保留首交也可能击中错误层。原始输入集合不同，不能排名或直接归因算法。
