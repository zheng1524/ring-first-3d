# 二、第一原则：原始Ring-First的特色必须完整保留

## 2.1 不得改变Torus物理模型

优先复用原始：

`ring_anchor_3d/geometry.py::torus_contours()`

以及：

- `ring_first_v5/g5_common.py`

这些文件位于此前提供的Ring-First历史源码研究包中；必须找到实际源码并核验版本，不得只根据报告重新猜测实现。

Torus满足：

\[
(\sqrt{x^2+y^2}-R)^2+z^2=r^2
\]

所有物理参数从原始组资产读取。

对于R10：

\[
R=5.6\ \mathrm{mm},
\qquad
r=0.6\ \mathrm{mm}
\]

这里的 \(r\) 是线材截面半径，不是独立需要估计的参数。

不允许将Torus替换为：

- 两个共面圆；
- 没有厚度的Ring；
- 简单二维椭圆；
- 自由形变CAD；
- 未认证的新网格近似。

允许使用网格CAD进行独立渲染与物理评价，但不允许默认用021存在缺陷的网格轮廓优化器替换原解析Torus。

## 2.2 必须保留真实可见边界规则

观测来自实际Ring/Polyp/Background分割及原有DXY几何。

必须继续区分：

- 可确认的Ring自身可见Inner边；
- 可确认的Ring自身可见Outer边；
- Ring与Polyp邻接但无法确定是否被遮挡的区域；
- CAD真实自遮挡；
- 未观测或不确定区域。

**不能将完整拟合椭圆外推部分作为真实可见边界。**

不得为了让CAD轮廓闭合而补充假观察。

Mid允许作为几何诊断或经过校验的弱约束，不能作为与Inner/Outer完全独立的第三份真值重复加权。

DXY主线严格只读。

## 2.3 Ring轴对称性必须正确处理

原始Ring-First连续优化五自由度。

Ring对绕自身法向的yaw不提供独立信息。

必须验证：

\[
\frac{\partial L_{\mathrm{Ring}}}{\partial\psi}
\approx0
\]

这里的导数是对保持Ring实体相对几何不变的轴对称变换求导，而不是对相机任意欧拉角变化求导。

不得让离散采样、轮廓点编号或数值误差制造虚假的yaw梯度。

法向翻转与连续yaw候选需要沿用历史V8/V9的正确分支处理。

# 四、统一相机几何和参数化

每个物理测量组拥有独立的Ring公制世界坐标。

对于同组视频 \(v\) 的第 \(i\) 帧：

\[
\boxed{
T_{v,i}^{c2w}
=
H_v
\exp(\widehat{\delta\xi_{v,i}})
T_{v,i}^{RF}
}
\]

其中：

- \(T_{v,i}^{RF}\)：原始Ring-First恢复的公制相机；
- \(H_v\)：该视频坐标到组级公制世界坐标的共享SE(3)；
- \(\delta\xi_{v,i}\)：受限的局部相机修正。

这一表达式只定义层级参数化。具体左乘坐标、旋转和平移方向必须通过源码单元测试确认，所有残差采用一致约定。

对于参考视频004：

\[
H_{004}=I
\]

对于具有真实跨视频约束的视频005：

\[
H_{005}\in SE(3)
\]

其他视频仅在存在真实可验证配准关系时才引入对应共享变换。

**禁止使用Sim(3)自由尺度来吸收公制误差。**

Ring物理尺寸固定，相机内参原则上冻结。

# 五、优化目标

统一损失：

\[
\boxed{
L=
\lambda_R L_{\mathrm{Torus}}
+
\lambda_F L_{\mathrm{SIFT}}
+
\lambda_P L_{\mathrm{pose}}
+
\lambda_X L_{\mathrm{landmark}}
}
\]

其中：

### 1. Torus几何残差

\[
L_{\mathrm{Torus}}
=
\sum_i
\sum_{u\in\Omega_i}
\rho_R
\left(
\frac{d(u,\Gamma_{\mathrm{Torus}}(T_i))}
{\sigma_{R,i}}
\right)
\]

必须使用原始解析Torus的真实投影与可见边身份。

在计算导数时优先使用解析或自动微分；对离散可见性和对应关系，采用固定局部对应、优化后重计算的方式处理。

若原始Torus投影实现无法直接自动微分，应隔离该模块进行验证，而不是更改物理模型。

### 2. RGB重投影残差

\[
L_{\mathrm{SIFT}}
=
\sum_{i,j}
\rho_F
\left(
\left\|
\Sigma_{ij}^{-1/2}
\left[
\pi(K_iT_i^{-1}X_j)-u_{ij}
\right]
\right\|
\right)
\]

其中：

- \(X_j\)：同一静态场景的真实共享三维地标；
- \(u_{ij}\)：真实SIFT像素观测；
- \(\Sigma_{ij}\)：观测协方差或明确记录的噪声尺度模型。

不能把多个具有相同物理身份的观测错误地作为独立地标。

### 3. 位姿正则

局部相机更新必须受约束。

优先保护：

- 原始Ring-First公制尺度；
- 同视频相对运动；
- 可辨识性较低的自由度；
- 已通过独立几何检验的相机关系。

这里的正则并非强迫所有相机保持原样，而是防止优化器通过不受观测支持的漂移降低训练损失。

### 4. 地标先验

已有三维SIFT地标是原始相机三角化结果，不是GT。

允许在BA中逐步释放共同地标更新。

但必须固定规范，防止相机与地标一起发生无意义的刚体漂移。

不要把联合BA误写成独立的SIFT损失加上另一份重复计数的重投影损失。

# 十四、研究边界

本轮不得：

1. 修改原始Ring-First物理尺寸或解析Torus定义。
2. 将Inner/Outer简化为两个共面圆。
3. 修改DXY算法主线。
4. 使用息肉GT选择相机。
5. 使用HERO或主体驱动相机BA。
6. 修改HERO原生深度或Mesh。
7. 为了消除错层，对HERO进行ICP二次对齐。
8. 开始共享主体训练。
9. 开始TSDF、Poisson或概率曲面融合。
10. 把原生深度的反事实重表达称为重新推理的HERO。
11. 将Ring IoU改善等同于绝对相机精度提高。
12. 在没有真实连接的情况下，强行将不同视频合并。

允许对旧代码进行必要的接口封装，但必须保留原始代码和行为对照。

**Q1：** 原始Ring-First五自由度几何与Ceres联合BA能否无损统一？

**Q4：** 相对于旧021，新方法是否解决了错误梯度和独立逐帧优化的问题？

**Q5：** 四组Ring与SIFT独立几何指标能否同时改善，或至少不发生明显退化？

**Q6：** 视频级共享SE(3)优化与真正联合BA分别带来多少收益？

**Q7：** 多HERO曲面在共同公制坐标中的错层是否减小？

**Q8：** 剩余错层主要表现在哪些位置、观察方向和来源组合？

**Q9：** 哪些相机可以冻结并进入下一阶段共享主体优化？

**Q10：** 当前是否具备引入全部12张独立照片的条件？

最终科研判断必须同时基于：

\[
\boxed{
\text{Ring几何}
+
\text{RGB多视角一致性}
+
\text{HERO独立曲面证据}
}
\]

其中HERO只参与冻结后的诊断，不参与相机候选选择。

**本轮的最终目标不是生成一张看起来融合成功的三维模型，而是建立一套真正统一、可验证的Ring-First公制相机体系，为后续共享主体和概率曲面融合提供稳定输入。**
