# 深度处理决定（P1完成，先于真实网络检查）

本轮只诊断原生HERO，不修改深度。两个视频独立，12个方向不能视作12个独立物理样本。

1. 系统/局部问题：6个参考中4个满足预注册的方向稳定条件，标为POSSIBLE_REFERENCE_BIAS；这不是实际偏移量认证。逐源局部MAD、空间连通冲突和宽残差分布见CSV，不能用一个中位数消除局部误差。
2. Ring证据：使用原生Ring Mask、独立Ring资格与固定CAD首交点，不使用E2的Polyp集合或M3小残差筛选。Ring材质/高光/边界和相机误差仍是混杂因素。Ring半区中位数仅作为有界诊断锚点；12方向中5个的固定对应线性反事实中位绝对残差下降，不能认作校正后真实精度。
3. 相机/对应：可能是主要限制之一；所有相机冻结，本轮没有独立相机真值。投影候选和循环/法向条件子集分别报告；未认证对应保留为未知，不强迫纳入物理误差。设计矩阵的数值秩不能解决相机与深度偏移的物理混淆。
4. 首轮方案：保留D0原生HERO和D1现有稳健/来源权重；权重1/0.25和相关分量归一不随预测表现调整。它们足以作为可证伪的初始监督合同，不保证能化解统一SDF上的所有深度矛盾。
5. D2：本轮不建立正式校正输入，不拟合自由scale+shift，不进行逐像素修正。绝对Polyp参考偏移仍不可辨识。当前不建议将D2纳入首轮正式MVP；若未来独立相机证据和Ring到Polyp误差迁移得到支持，才另行预注册±1mm单常数偏移消融，保留原生对照。

因此当前结论是：存在条件性的系统偏移迹象及局部/对应冲突，不能归结为全部需要“校正HERO”；D2目前证据不足。完整数值见metrics/DEPTH_BIAS_DIAGNOSTICS.csv、BIAS_DESIGN_IDENTIFIABILITY.csv和RING_BIAS_EXPLANATION_COUNTERFACTUAL.csv。
