# 三、核心创新：息肉几何与SIFT联合确定旋转方向

本阶段是019最重要的研究内容。

建议将方向恢复划分为两条互补路径，并在同一个候选空间内联合验证。

## 3.1 路径A：Ring—息肉相对几何

从现有可靠主体及可信HERO中提取：

- 息肉主体核心中心；
- 头部中心候选；
- 主体主方向；
- 基底与Ring的相对位置；
- 具有稳定三维支持的非对称几何特征。

优先使用可信区域。

不要求G01的整个HERO表面完全正确。

特别注意避免：

- 使用异常拉伸面片确定主体中心；
- 将部分可见曲面质心直接视作真实完整主体质心；
- 让Ring附近的错误曲面主导方向估计。

构建Ring平面内的方向：

\[
d_v=
(I-n_vn_v^\top)(h_v-c_v)
\]

使用两个视频的方向估计：

\[
\psi_{\mathrm{shape}}
\]

如果投影方向过短、主体近对称或可见区域明显不同，则降低该证据的可信度。

不得强行输出唯一方向。

应保留多个几何候选。

## 3.2 路径B：基于SIFT的公制三维视觉地标

这是本轮建议重点新增的机制。

我们拥有同视频内已知的相机轨迹。

因此可以在video004内部：

1. 使用真实RGB进行SIFT特征提取；
2. 建立跨帧特征匹配；
3. 通过几何验证和多帧跟踪筛选静态特征；
4. 利用已有Ring-First公制相机进行多视角三角化；
5. 在必要时使用可信HERO深度辅助确认三维位置；
6. 得到少量稳定、可追溯的公制三维地标。

将这些地标记为：

\[
\mathcal L_{004}
=
\{X_k^{004},d_k,\Sigma_k,\mathcal O_k\}
\]

其中：

- \(X_k^{004}\)：三维位置；
- \(d_k\)：视觉特征描述；
- \(\Sigma_k\)：几何不确定性；
- \(\mathcal O_k\)：实际支持它的图像观测。

随后，在video005中寻找相同静态结构的SIFT特征。

使用：

- 可靠2D–3D对应时的PnP；
- 仅有2D–2D对应时的极线几何；
- RANSAC；
- 相机可见性；
- Ring遮挡信息。

生成跨视频旋转候选：

\[
\psi_{\mathrm{SIFT}}
\]

这与直接对两个HERO点云运行ICP不同。

**我们希望用真实静态视觉地标确定两段视频的相对方向，而不是依赖两份可能存在系统偏差的密集深度图相互贴合。**

优先尝试：

- Polyp表面的真实纹理；
- 稳定的背景特征；
- Ring附近具有明确纹理身份的结构。

避免将高光、光滑对称Ring边缘或重复图案当作可靠材料点。

背景特征若缺乏可信深度，可保留为2D–2D约束，不强行为其生成三维位置。

SIFT不足时，可审计并复用历史LightGlue/RoMa匹配，但必须保留对应方法的独立身份，不得用其他模型结果冒充SIFT。

## 3.3 多候选联合

不得简单将：

\[
\psi_{\mathrm{shape}}
\quad\text{与}\quad
\psi_{\mathrm{SIFT}}
\]

算术平均。

应建立多个候选：

- Ring＋主体几何；

# 四、全角度搜索：不再被错误初始角度限制

必须执行完整360°搜索。

建议先采用：

\[
\psi=0^\circ,5^\circ,\ldots,355^\circ
\]

再对具有竞争力的候选进行连续角度精修。

这里的5°是首轮计算网格，不是最终精度限制。

不得因为历史相机Gate仅允许±5°或±10°，就放弃大角度搜索。

尤其应保留历史约90°旋转候选附近的完整比较。

## 4.1 关键目标：整段视频一致性

以video004的冻结主体Mesh为参考。

给video005施加同一个视频级变换：

\[
C'_{005,i}
=
T_{004\leftarrow005}C_{005,i}
\]

所有目标视频帧必须共享同一个 \(T\)。

使用PyTorch3D渲染冻结主体。

计算：

\[
\boxed{
L_{\mathrm{search}}(\psi)
=
\lambda_PL_{\mathrm{Polyp}}
+
\lambda_FL_{\mathrm{Feature}}
}
\]

其中：

\[
L_{\mathrm{Polyp}}
=
\sum_iw_i
L_{\mathrm{silhouette}}
\left(
\operatorname{Render}(M_{004},C'_{005,i}),
S_{005,i}
\right)
\]

\(L_{\mathrm{Feature}}\) 来自有效SIFT约束。

Ring几何用于定义候选变换、保持公制锚点，并独立检查投影一致性。

需要特别注意：

Ring对称意味着其理想几何不应在一维搜索中提供虚假的yaw梯度。

但Ring与息肉之间的真实遮挡关系，可以为整体静态场景提供额外验证。

## 4.2 不允许只看单帧

必须同时展示：

- 多帧总体损失；
- 各帧独立轮廓误差；
- SIFT几何残差；
- 不同角度的损失曲线；
- 前几个候选的真实图像投影。

避免某个角度只在一帧上效果很好，却在其他帧上明显错误。

# 五、PyTorch3D进行视频级六自由度精修

完成全角度搜索后，选择若干事前规则确定的优秀候选。

使用PyTorch3D与PyTorch Autograd进行局部精修。

优化变量首先只有：

\[
\delta\xi\in\mathfrak{se}(3)
\]

最终：

\[
T_{\mathrm{refined}}
=
\exp(\widehat{\delta\xi})T_{\mathrm{candidate}}
\]

主体Mesh、HERO和原生相机全部固定。

联合目标：

\[
\boxed{
L_{\mathrm{pose}}
=
\lambda_RL_{\mathrm{Ring}}
+
\lambda_PL_{\mathrm{Polyp}}
+
\lambda_FL_{\mathrm{SIFT}}
+
\lambda_TL_{\mathrm{prior}}
}
\]

分别代表：

- Ring真实可见内外边界与CAD；
- 多视角Polyp轮廓；
- SIFT对应及三维地标重投影；
- 对Ring锚点、视频内部相对轨迹的合理偏移约束。

优先复用现有PyTorch3D：

- `Meshes`
- `MeshRasterizer`
- `SoftSilhouetteShader`
- `cameras_from_opencv_projection`
- PyTorch Autograd

复用历史Ring-aware遮挡处理。

允许利用OpenCV完成SIFT、PnP和RANSAC。

不再从零实现光栅化、PnP或通用非线性优化器。

## 5.1 允许合理的相机微调

Ring中心、法向和原始相机存在真实估计误差。

因此，精修不能简单要求Ring中心数学上绝对不动。

应该允许小范围修正，但必须检查：

- Ring CAD投影是否改善；
- 真实内外边界是否仍然吻合；
- 是否产生不合理的Ring位置偏移；
- 这种变化是否同时改善多个视角。

不得通过牺牲Ring来换取较低的背景或Polyp残差。

历史GICP越界失败必须作为对照证据，但不能把旧经验阈值当作无需实验的绝对结论。

## 5.2 第一轮禁止联合改变主体

即使当前018主体不完全正确，也不得同时开放主体顶点更新。

否则无法区分：

- 跨视频姿态改善；
- 主体几何形变补偿；
- HERO深度错误。

本轮必须先判断冻结主体能够支持多大程度的跨视频配准。

如果主体不准确导致轮廓项出现系统性偏差，应通过SIFT和其他独立几何证据区分，而不是直接让Mesh变形。

# 六、独立辅助实验：利用Ring检查HERO深度偏差

该阶段独立于跨视频主配准。

不得预设黑色Ring的HERO预测一定准确。

## 6.2 复用DXY中的可见Ring边界

使用 `new-polyp-dxy` 的二维内外环识别和稳定性诊断。

选择Ring材料内部的可靠像素，避免：

- 内外轮廓附近；
- Polyp遮挡；
- 高光；
- 严重低纹理区域；
- CAD投影明显不一致的区域。

不能简单使用完整Ring Mask中的全部像素。

## 6.3 使用完整Ring CAD第一可见表面

将CAD投影到当前相机：

\[
D_{\mathrm{CAD}}(u,v)
\]

这里必须使用真实截面厚度：

\[
1.2\ \mathrm{mm}
\]

不能使用二维Mid中心线代替可见实体表面。

与HERO深度比较：

\[
\Delta D_i=
D_{\mathrm{HERO},i}
-
D_{\mathrm{CAD},i}
\]

首先统计：

- 有效Ring深度比例；
- 中位残差；
- MAD；
- p95残差；
- 不同Ring区域的系统差异；
- 同视频不同来源的重复性。

## 6.4 先测试简单的来源级深度偏差

估计：

\[
\boxed{
b_i=\operatorname{median}(\Delta D_i)
}
\]

构造派生深度：

\[
D_i'=D_i-b_i
\]

随后检验：

1. Ring区域残差是否下降；
2. 同视频Polyp HERO是否更一致；
3. G01跨视频HERO是否更一致；
4. 该偏差是否在不同Ring可见子区域之间稳定；
5. 是否存在修正Ring但损害Polyp的情况。

**只有发现具有合理物理支持的系统偏差，才允许进一步开展校正实验。**

不能仅凭Ring上拟合出一个数值，就把它直接应用到整个息肉深度图。

原始HERO不得覆盖。

不必在本轮开发复杂的逐像素深度校正网络。

# 七、相机改善之后，重新运行官方HERO进行验证

这是019非常有研究价值的最终验证。

由于MVSAnywhere HERO使用相机位姿作为输入，相机修正可能改变深度预测。

因此，对于已经得到明确改善证据的视频级位姿候选，开展以下对照：

**H0：原始相机＋原始HERO**

历史基线。

**H1：修正相机＋原始HERO**

只改变相机外参，不重新推理深度。

用于判断投影几何改善。

**H2：修正相机＋重新推理HERO**

调用现有官方MVSAnywhere模型。

权重保持冻结。

使用真实RGB及修正后的派生相机。

输出新HERO及完整来源记录。

注意：跨视频共同SE(3)坐标变换本身只是坐标系变换。如果HERO输入的相机相对几何没有改变，重新推理不应被预期自动产生新的深度信息。

因此，H2只有在相机**相对位姿确实发生物理意义上的修正**时，才可能带来不同结果。

必须区分：

- 纯视频级坐标规范统一；
- 实际相机相对位姿校正。

不能把前者包装成新深度预测能力。

# 十四、最终研究原则

我们此前多次失败，主要问题不是缺少通用优化算法，而是没有充分发挥现有物理场景的特殊结构。

本轮应当坚持：

**Ring不是普通点云，而是具有精确尺寸和旋转对称性的公制几何锚点。**

**息肉不是普通匹配区域，而是与Ring静止连接、具有非对称三维形态的辅助方向锚点。**

**SIFT不只是两张图像的对应，而可以结合已知公制相机轨迹形成稳定的三维视觉地标。**

**整段视频不应逐帧独立配准，而应作为共享刚体相机系统进行联合优化。**

因此，本轮真正要验证的核心假说是：

\[
\boxed{
\text{Ring公制几何}
+
\text{Polyp非对称结构}
+
\text{SIFT三维地标}
+
\text{多视角联合渲染}
\Rightarrow
\text{更稳定的跨视频配准}
}
\]

优先使用成熟的PyTorch3D、OpenCV及现有Ring-First实现。

不开发新的大规模网络，不重新训练SDF，不修改主体，不改变DXY主线。

**目标是第一次获得能够同时解释G01两段视频真实图像、Ring和静态息肉几何的共享公制位姿。**

完成后提交全部结果，等待人工审核，不自动开展曲面融合。
