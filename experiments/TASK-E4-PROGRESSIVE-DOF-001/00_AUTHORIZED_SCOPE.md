# 用户授权回执：最小渐进几何自由度实验

来源：本会话用户直接授权，基于TASK-E4-2D3D-OBSERVABILITY-001 Gate A；不是旧Gate B/C/D的自动放行。

目标：初始椭球同时存在整体/局部偏差时，多视角Mask能否通过逐步释放自由度接近独立Blender GT。

1. 独立副本保护原Gate A；复用同一IIa6.5原生GT、五相机、Ring、Mask、三拟合两留出，不重新生成实验数据。
2. 完全相同P0先开放中心XYZ和三个半轴六参数，旋转固定，复用SDF网格和投影。
3. 再增两个有相反扩张/收缩能力的Wendland核，位置仅由拟合轮廓残差提出；先固定中心更新幅度，有有效信号才释放中心。
4. 沿用Powell和同一轮廓目标；固定残差诊断与真实loss不一致需分开审计，不同时替换目标。
5. 保存P0、六参、局部阶段；统一报告拟合/留出IoU、Chamfer MAE/p95、独立空间差异体积、扩张/收缩、Ring和连续性。
6. 全部优化结果冻结后GT才能参与三维评价；分析整体/局部贡献。
7. 只一场景一次渐进运行，不做超参搜索、其他息肉、DXY改动或Gate B/C/D。完成后回答六参是否纠偏、双核是否改善真实几何、二维/三维改善是否一致；不一致只依保存证据归因，不直接换更复杂模型。

具体数值、预算、逐核信号门槛与11/14维条件释放见运行前协议。若无信号，明确NOT_TRIGGERED，不制造新的实验臂或反复重启。
