# Body-guided HERO relocalization: preregistered design

Four groups in order G03,G05,G01,G06; all 75 prior native FIT HERO sources, including two separately labeled photos. Body-E freshly fits nine-parameter ellipsoid from three complementary reference-video image masks/ellipses and fixed metric cameras, with no HERO points or previous fitted mesh parameters. A1 analytic conic projection/ray roots are reused. Body-U is exact frozen formal R3 B3 FINAL. Both Bodies use identical source/seed/budget/evaluation sets.

A0 native; A1 exact execution replay of prior B1 ray bias workflow at its original frozen018 Body; A2-E/U use the new same region-resection algorithm. A1 is a historical baseline, never an initializer or fallback for A2.

A2 defines camera-local HERO coordinates as immutable. For every target, observed 2D core ellipse and normalized polar cells establish region candidates on the Body first visible surface. No source-to-Body 3D-nearness requirement. Thin/outside-core observations are UNKNOWN for fitting, retained in the full rigid mesh. Ring-relative geometry, normal/first-layer/CAD order are audited. Four Ring-normal yaw starts and two ellipse phase identities keep directional ambiguity. Fixed candidates feed mature SciPy robust SE(3) resection together with actual CAD silhouette and background-only SIFT epipolar constraints to frozen reference cameras. Two correspondence rounds, no Body update, no local/nonrigid deformation, no ICP.

HERO and its derived target camera transform by the SAME rigid H; source camera-local coordinates, edge lengths, curvature, own image projection and stalk shape are invariant. This pilot releases source-level derived resection candidates, not a new formal video trajectory or independent camera certification. It is intentionally different from019-021 shared-video SE(3), whose same-video relative geometry is invariant. Independent background references remain frozen.

Background mutual SIFT matches are deterministically split70%/30% BEFORE RGB-RANSAC and pose optimization. Ring uses the source material Mask as a separate physical constraint; final full CAD raster validation is an independent operator on the same Ring observation, not unseen Ring pixels. The independent subset and all protected image/HERO views are read only after every pose candidate is frozen. FIT objective chooses the numerical candidate; independent gates only label validation/rejection, never choose an alternative winner. Rank/condition is computed on Ring+background data, excluding Body/prior. Near-tie pose alternatives yield AMBIGUOUS/UNKNOWN. Missing constraints retain candidates but do not certify a relocalization. Failed sources keep NaN for accepted pose; native A0 is shown as its separate baseline, never silently substituted.

Controlled tests use the existing static Blender IIa scene and fixed camera/Ring/assets. Ideal depth is labeled IDEAL_GT_DEPTH_UPPER_BOUND. C1 additive axial depth error is not rigid in3D; strict-shape A2 may fail and must report this structural limit. C2 known rigid pose perturbation; C3 large initial mislocalization beyond old1mm gate; C4 distinct/occluded surface subsets; zero perturbation. Synthetic GT is isolated from real fitting and only supports control construction/evaluation. No control/holdout outcome tunes real weights.

Exact region objective before any pose run: equal block mass .5 metric 3D residual (sigma1mm) and .5 actual Body-Q→source-pixel reprojection (sigma3px), plus Ring material support, background FIT Sampson, weak original-pose prior. Proper 3D alignment initializes the pose only; final solve is joint rigid camera resection. No source-world-nearness eligibility test.

Input identity clarification before any pose run: background splits are keyed by image-content identity (control source view identity) and fixed global seed, so C0/C1/C2/C3 use identical observations. No split depends on perturbation label or result.

Control-contract repair before real pose runs: CAD silhouette edges are extracted using the existing020 front/back-face adjacency and Open3D first-visible test, frozen inside each LS solve and reselected between correspondence rounds. Reverse Ring residual is point-to-projected-segment, eliminating point-sampling holes. Soft-L1 is applied per unnormalized physical residual, then block-count normalized; SciPy solves the equivalent transformed residual with linear loss. This preserves the declared noise scales instead of making them depend on N. Native-frustum bounds are enforced for candidate Body pixels. Initial control outcomes are archived, not selected against the corrected run.
