# 技术资产与历史保护规范

适用后续任务；本轮仅建规范，没有删除/移动/重命名历史文件，没有迁移 Git LFS。优先遵守用户范围与仓库治理。[本地资产入口](LOCAL_ARTIFACTS.json)是选择性实物核验，不能冒称全项目完整清单。

## 三层存储

| 层 | 应保存 | 必要身份与约束 |
| --- | --- | --- |
| Git | 被授权的源码/小配置、协议、冻结哈希、技术/失败报告、核心CSV/JSON、少量关键PNG、资产索引 | 一任务一分支/目录，显式git add；科学状态与分母齐全；不得批量上传未经授权的历史科研源码 |
| LOCAL_ONLY | 全预测、全逐次轨迹、完整图集、原视频/图像/分割/深度缓存、大型PLY/GLB/NPZ、权重/环境 | 保留原路径、bytes、完整SHA256、来源任务与生成命令/版本、存活状态、再生成条件；缺失显式登记 |
| External Storage / Git LFS | 经评估确实要跨机器共享的大二进制 | 先列出具体文件/大小/用途/权限/存储成本及替代方案，再人工审查；不用文件大为理由直接迁移或删除 |

文件格式不是唯一判据：少量小 NPZ 若授权且为关键证据可进 Git；全量 PNG 即使单图小也不应全推。大型 PNG 保存本地并提交精选关键图+哈希/索引；PLY/GLB 保存原几何与来源层，不只保留截图；NPZ 必须说明数组字段、dtype/shape、单位、frame、原生/插值状态与NaN语义。视频、权重、虚拟环境不进普通Git。

## 每项资产记录

LOCAL_ARTIFACTS 条目至少含 original_path、bytes、sha256、hash_verification、generating_task、dependency_versions、reproduce、regenerable 与 overwrite_original_allowed=false。生成输入应另列 source_id、原RGB/Mask/父RGB/相机/CAD/权重哈希，输出frame与单位；原始输入、清理派生、融合派生、先验推断分别建条目。哈希“实际重算”和“继承冻结清单未重算”明确区分，不按路径猜身份。

源码追溯：实验条目→报告/REPRODUCE→provenance冻结→源码commit+文件SHA256→具体函数及依赖→输入SHA→输出SHA。分支名可移动，commit与完整SHA才是复用依据；工作tree有改动应登记diff/冻结副本，不能用分支HEAD代替实际执行字节。

本轮 manifest 核验少量典型 camera/nativeZ/rawMesh/PNG 及旧完整manifest；权重只继承模型回执哈希并核对存在/bytes，不新读2.42GB权重。没有扫描全硬盘，也没有把被索引的原资产复制到本分支。

## 中间结果与复现

保留 raw、被拒提案、失败NaN、未收敛状态、旧版本纠错记录、GT访问/预测冻结证据。以任务ID/物理组/来源/阶段建立独立目录，复现写到新派生目录，不覆盖历史。复现环境包括Python/库/驱动、官方git commit/权重、坐标与随机状态、完整参数、真正的运行步数；计划步数不能冒充实际执行。仅有报告不等于已备份完整资产。

代码复用先查注册表：DIRECT_REUSE、AST_REUSE、ADAPTED_REUSE、REIMPLEMENTED如实记录；共享模块晋升须独立审查、测试与迁移方案，保留旧路径/版本链接。工程状态与科研状态独立升级，科学晋升须有明确范围的人工验收记录。

## 重复文件与历史删除审批

1. 先只读盘点，按完整SHA/bytes比较，区分byte相同、RGB重复来源与不同编码的相同内容；不能仅按文件名/相近指标去重。
2. 提交待清理清单：原路径、任务/上下游引用、哈希、字节、备份位置、可复现性、保留副本及链接更新方案，连同具体动作供人工审查。
3. 原始观测、唯一权重/预测、失败证据、旧算法或指标默认保留；再生成能力不等于获准删除。
4. 得到明确的具体删除授权后才操作；执行前核验备份哈希，保留删除回执/可恢复路径，不用git clean、force push或历史重写实现“清理”。
5. 注册表更新应与新任务交付同提交：只更新本任务验证过的事实；失败证据不得被后续成功覆盖。大型迁移/LFS另行审批，不混入文档任务。

静态历史资产的硬链接去重保留内容和全部路径。禁止原地修改这些历史副本；新任务必须复制到独立输出并用原子替换保存。原始观测、权重和唯一失败证据默认KEEP。Git历史与远端分支不通过本轮清理删除。
