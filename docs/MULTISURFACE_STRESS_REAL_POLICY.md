# Multisurface stress and real pilot

Schema 6 composes the original preflight/contracts, original 35 and scientific regressions, immutable schema-5 scientific algorithms and append-only Runner snapshots. It adds a data adapter, a predeclared separately named correspondence-schedule ablation and fixed-denominator summaries. Historical tasks and schemas remain unchanged.

```bash
bash tools/research/run.sh tools/research/policy.py check --task experiments/TASK-E4-MULTISURFACE-STRESS-AND-REAL-PILOT-001/TASK.yaml
bash tools/research/run.sh tools/research/policy.py run --task experiments/TASK-E4-MULTISURFACE-STRESS-AND-REAL-PILOT-001/TASK.yaml --run-dir experiments/TASK-E4-MULTISURFACE-STRESS-AND-REAL-PILOT-001/runs/STRESS_REAL_001 --stage preflight
```

Use the authorized stage order in TASK.yaml; `--stage all` is resumable and cannot skip prerequisites. `status` checks artifacts; `accept` verifies execution completeness, not scientific accuracy. Changes to inputs, algorithm files, code, protocol, permissions or budget require a new frozen run. A source/interface failure marks only the relevant real group NOT_EVALUABLE; simulation is independently runnable. New scientific negatives remain task-local candidate failure facts pending human review.

No GT best alignment, GT parameter choice, historic measurement fallback, new DXY candidate study, camera optimization or HERO inference/training is performed. The real input adapter reads original HERO meshes/depth, source pixels, immutable masks and formal DXY pixel descriptors. It runs fresh task-local FIT-only 2D initialization; complete mesh topology is preserved. Real held-out observations are not independent GT. All matrix variants and explicit failures remain inspectable offline.
