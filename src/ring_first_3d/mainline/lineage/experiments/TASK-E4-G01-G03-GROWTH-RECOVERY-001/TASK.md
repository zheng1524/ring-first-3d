# 3. 核心几何修改：允许柄部嵌入主体

这是本轮最重要的修改。

上一轮对柄部与主体的空间相交采取了过于严格的处理。

实际上，柄部根部与主体并不是两个互相独立的物体。真实的柄状息肉中，柄部应该从主体内部延伸出来，与主体形成有深度的连续连接。

因此：

**不得因为柄部在预定的根部嵌入区域与主体发生空间重叠，就将这次生长直接判定为自交失败。**

但必须严格区分预期嵌入与其他不合理相交。

## 3.1 建立嵌入式柄部模型

设原始主体为：

\[
B_0=(V_0,F_0)
\]

柄部中心线为：

\[
C(s),\quad s\in[0,L_{\mathrm{total}}]
\]

中心线参数方向统一为：

- 起点：主体内部的柄部近端。
- 终点：主体外部的柄部远端。

柄部近端不再恰好位于主体表面，而是向主体内部延伸一段距离。

定义：

\[
d_{\mathrm{embed}}>0
\]

表示柄部嵌入主体的深度。

要求：

1. 柄部从主体内部开始。
2. 柄部穿过主体原始表面。
3. 柄部在主体外部继续延伸。
4. 根部具有连续的空间连接。
5. 嵌入段不能形成额外的外露柄部。

嵌入深度必须根据局部主体厚度和根部截面尺度合理确定。

建议初始估计：

\[
d_{\mathrm{embed}}
=
\min(0.5r_{\mathrm{root}},0.25t_{\mathrm{local}})
\]

其中：

- \(r_{\mathrm{root}}\)：根部截面的代表性半径。
- \(t_{\mathrm{local}}\)：根部附近主体的局部厚度。

该公式仅作为几何初始化，不是必须固定的最终值。

最终每组的嵌入深度必须在正式优化前确定并写入配置，不能利用 GT 调整。

如果无法可靠估计局部厚度，应报告原因，不得无限增加嵌入深度。

## 3.2 明确柄部长度的定义

这是必须严格执行的指标定义。

使用冻结的原始主体 \(B_0\) 构造有符号距离场：

\[
\phi_{B_0}(x)
\]

约定：

- 主体内部：\(\phi<0\)
- 主体表面：\(\phi=0\)
- 主体外部：\(\phi>0\)

从柄部近端向远端沿中心线采样。

找到中心线第一次由主体内部穿出主体表面的交点：

\[
s_{\mathrm{exit}}
=
\min\{s:\phi_{B_0}(C(s))=0,\ 
\text{且随后向主体外部运动}\}
\]

这个位置定义为：

**柄部与主体的实际交界位置。**

那么：

嵌入长度：

\[
L_{\mathrm{embed}}=s_{\mathrm{exit}}
\]

实际柄部长度：

\[
\boxed{
L_{\mathrm{stalk}}
=
L_{\mathrm{total}}-s_{\mathrm{exit}}
}
\]

注意：

- 不得使用柄部近端到远端的总长度作为最终柄长。
- 不得将主体内部的嵌入段计入柄长。
- 不得简单使用端点之间的直线距离代替中心线弧长。
- 应沿 B-spline 中心线计算实际弧长。

最终必须同时报告：

| 指标 | 定义 |
|---|---|
| Total Centerline Length | 完整中心线弧长 |
| Embedded Length | 位于主体内部的中心线长度 |
| Exposed Stalk Length | 穿出主体表面至柄部末端的中心线长度 |
| Embedding Depth | 根部实际嵌入深度 |
| Exit Point | 中心线穿出主体表面的位置 |

其中，只有 Exposed Stalk Length 才是最终报告的息肉柄长。

## 3.3 嵌入段的几何处理

允许构造阶段的柄部 Sweep 与原主体发生预期重叠。

但是最终输出必须是一个统一的、拓扑合理的外部 Mesh。

优先采用：

- 稳健的 Mesh Boolean Union；
- 或者局部表面裁剪与拓扑 Stitching。

具体方式根据仓库现有成熟几何代码选择，不要无必要引入新的依赖。

需要实现：

1. 保留原始主体外部有效表面。
2. 保留柄部穿出主体之后的真实外部表面。
3. 去除嵌入段中被主体覆盖的内部表面。
4. 正确处理柄部与主体交界处的连接边界。
5. 形成连续的外部 Mesh。
6. 不允许留下两套互相穿透的内部三角面。

特别注意：

**原始主体与柄部在嵌入区域发生的预期空间重叠，不属于应当直接拒绝的几何自交。**

但是：

- 柄部自身发生自交，拒绝。
- 柄部在嵌入区域以外穿入主体，拒绝。
- 柄部与主体在非预定区域发生相交，拒绝。
- 柄部与 Ring 发生不允许的碰撞，按照 Ring 门控处理。
- 最终融合 Mesh 存在非流形边、内部重复面或非预期自交，拒绝。

不得简单地将所有 `SELF_INTERSECTION` 检查关闭。

应该将预期嵌入区域作为明确的几何例外，并对最终统一 Mesh 执行完整检查。

## 3.4 修改 Clearance Loss

原来的 Clearance Loss 不适合直接用于嵌入式连接，因为它会试图把所有柄部采样点推离主体内部。

必须区分：

A. 近端嵌入区域：

允许中心线和柄部实体位于主体内部。

不施加将其强行推出主体的避碰损失。

B. 穿出区域：

中心线应当从内部连续穿过主体表面。

必须记录第一次穿出的位置。

C. 远端外露区域：

不允许重新进入主体。

保持合理的空间距离，避免柄部穿过主体其他部分。

可以使用：

\[
E_{\mathrm{clearance}}
=
\sum_{s>s_{\mathrm{exit}}}
\max(0,-\phi_{B_0}(C(s))-\epsilon)^2
\]

实际实现时，对截面采样点也要检查，不能只检查中心线。

在交界过渡区域允许正常的主体—柄部连接。

## 4.1 渐进式生长

采用三阶段 continuation：

- Stage 1：恢复较短的嵌入式柄部，先确保连接合理。
- Stage 2：逐步增加外露柄部长度。
- Stage 3：在二维轮廓支持下优化最终长度和截面。

每阶段都重新执行：

1. B-spline 曲线生成。
2. RMF 截面生成。
3. 嵌入区域和穿出位置计算。
4. 统一 Mesh 生成。
5. 二维投影。
6. 几何检查。

如果产生非预期自交，缩小本阶段更新步长重新优化。

不得通过删除自交面片制造合法 Mesh。

## 4.2 联合目标函数

保留：

\[
E=
E_{\mathrm{2D}}
+\lambda_c E_{\mathrm{clearance}}
+\lambda_b E_{\mathrm{bend}}
+\lambda_r E_{\mathrm{radius}}
+\lambda_a E_{\mathrm{attachment}}
+\lambda_e E_{\mathrm{embed}}
\]

其中：

- \(E_{\mathrm{2D}}\)：多视角二维轮廓对应误差。
- \(E_{\mathrm{clearance}}\)：外露柄部的空间避碰。
- \(E_{\mathrm{bend}}\)：中心线平滑。
- \(E_{\mathrm{radius}}\)：截面变化平滑。
- \(E_{\mathrm{attachment}}\)：交界区域法向与表面连续性。
- \(E_{\mathrm{embed}}\)：嵌入深度的约束。

二维轮廓仍然是主要数据依据，几何先验只负责避免不合理形变。

# 6. 修改 RingCollisionGate

本轮第二个明确修改重点。

**只有本次更新使 Ring 碰撞加重时，才拒绝本次更新。**

比较：

\[
\Delta E_{\mathrm{ring}}
=
E_{\mathrm{ring}}(B_{\mathrm{candidate}})
-
E_{\mathrm{ring}}(B_{\mathrm{current}})
\]

不再将初始状态和当前状态中较严格的逐点阈值作为唯一验收依据。

保留初始状态用于诊断。

必须双向检查：

- Body → Ring
- Ring → Body

分别记录：

- 最大穿透深度。
- 穿透面积。
- 面积加权穿透能量。

判定：

| 情况 | 结果 |
|---|---|
| 穿透减少 | 允许 |
| 穿透保持不变 | 允许 |
| 无 Ring 接触关系 | 允许 |
| 局部或整体碰撞明显加重 | 拒绝 |
| 数值误差范围内波动 | 允许 |

根部嵌入主体不等于允许柄部穿透 Ring。

嵌入例外只适用于柄部与 Polyp Body 的预定连接区域，不能扩展到 Ring。

所有容差必须在正式预测前冻结。

# 12. 最终研究原则

本轮必须遵守以下几何定义：

**柄部是从主体内部延伸出来的连续结构，而不是一个刚好贴在主体表面的独立物体。**

因此：

- 允许柄部向主体内部嵌入。
- 允许嵌入区域与主体发生预期的空间重叠。
- 嵌入区域用于建立可靠连接，不计入柄长。
- 柄长从柄部中心线第一次穿出主体表面的位置开始计算。
- 最终输出应是一个统一的、连续的外部 Mesh。
- 不允许将预期嵌入与其他区域的非正常自交混为一谈。

**最终目标不是获得两个漂亮的三维模型，而是证明原本被拒绝的多视角生长候选，经过最小修复后，能够在保持几何真实性和二维观测一致性的条件下，形成具有真实嵌入连接的柄部，并正确测量其外露长度。**
